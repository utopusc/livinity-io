Required failure modes (named verbatim per CONTEXT line 15):
      1. `## Failure: Display gone away` — X session crashed / user logged out / DISPLAY env stale. Diagnose: `xdpyinfo -display "$DISPLAY"` returns "unable to open display". Fix: re-resolve DISPLAY (`who | awk '{print $5}'`), or re-launch X session, or wait for next graphical login.
