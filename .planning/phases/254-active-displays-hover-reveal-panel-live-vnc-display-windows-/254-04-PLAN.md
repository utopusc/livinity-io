## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-254-11 | I (Information Disclosure) | strip listing displays owned by another session | accept | displays.list is intentionally global (any authenticated session can SEE the inventory — matches displayManager.list() / MCP semantics). CONTROL of a display still requires getVncUrl's owner-scoped authz (Plan 01 T-254-01), so listing a non-owned display does not grant access to it. |
| T-254-12 | E (Elevation) | clicking a non-owned display row to control it | mitigate | The click triggers getVncUrl which FORBIDs non-owned (non-host) displays (Plan 01). The window will show an error overlay (Plan 03) rather than a usable stream. |
| T-254-13 | T (Tampering) | display id injected via UI | mitigate | display ids originate from displays.list server data; getVncUrl re-validates with the `^:\d+` zod regex server-side. |
