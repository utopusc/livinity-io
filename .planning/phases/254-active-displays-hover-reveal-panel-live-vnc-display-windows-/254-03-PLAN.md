<objective>
Build the live, interactive VNC display window (locked decision #1: reuse the noVNC/RFB infra) and the window-content routing + openWindow sizing it needs. A LivOS window whose appId is `DISPLAY_:N` resolves that display's VNC websocket via the new `displays.getVncUrl` tRPC (Plan 01) and renders it through the existing `useWebAppVnc` hook with `viewOnly:false` so mouse + keyboard are forwarded natively over the VNC protocol (no screenshot-polling, no per-event tRPC dispatch — unlike the WebApp path which uses xdotool).

Purpose: Clicking a display in the hover panel (Plan 04) opens it as a usable desktop window. This plan delivers the window content + the sizing seam; Plan 04 wires the panel that calls openWindow.
Output: New `x11-display-stream-window.tsx`; a `DISPLAY_` routing branch in window-content.tsx; an extended `openWindow` signature accepting suggested WxH.
</objective>
