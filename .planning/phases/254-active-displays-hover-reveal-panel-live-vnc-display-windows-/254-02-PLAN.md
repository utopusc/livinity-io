<objective>
Change the main host X display `:1` creation resolution (currently the hardcoded literal `'1920x1080x24'` in livinityd boot, index.ts:892-894) so it derives from the SAME default-resolution constant the MCP display-creation path uses (`displayManager.create()` defaults — `DEFAULT_WIDTH`/`DEFAULT_HEIGHT` in display-manager.ts:52-53). This is locked decision #3: the `:1` resolution must match the MCP display-creation size, sourced from one constant rather than two independent hardcodes.

Purpose: Today `:1` is hardcoded `1920x1080` in index.ts and the MCP `computer_create_display` defaults are independently hardcoded `1920x1080` in display-manager.ts. They agree today but drift independently. Locking them to one exported constant satisfies the operator's "make :1 match the MCP display-creation size" intent and removes the divergent hardcode.
Output: `DEFAULT_DISPLAY_WIDTH`/`DEFAULT_DISPLAY_HEIGHT` exported from display-manager.ts (re-exported by the displays barrel); the `:1` startXvfb call in index.ts builds its `resolution` string from those constants.
</objective>
