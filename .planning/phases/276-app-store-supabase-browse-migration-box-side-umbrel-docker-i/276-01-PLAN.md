<objective>
Remove the dead Umbrel `auth-server` image end-to-end: delete the `auth` service from the
legacy-compat compose, remove the pull/retag of `getumbrel/auth-server:1.0.5 → livos/auth-server:1.0.5`
from BOTH install scripts (lockstep), and remove the now-obsolete install-script tests that assert the
removed machinery exists.

This is the safe, independent quick win (CONTEXT/RESEARCH sequencing step 1). LivOS auth is
Caddy `forward_auth` → livinityd `/auth/verify`; nothing routes to the Umbrel auth-server.

NOTE: `tor_proxy` is removed in a SEPARATE later plan (276-05) after a box runtime check. This plan
removes ONLY the `auth` service and the `auth-server` image lines. The `_dld_setup_docker_images()` /
`setup_docker_images()` functions pull BOTH images, so removing them here also removes the `tor` pull —
that is intentional and safe (the `tor` image is also dead; plan 05 finishes the runtime tor removal).

Purpose: Stop pulling/retagging a deleted-from-use image on every fresh install; shrink the boot path.
Output: auth service gone from compose; both install scripts cleaned; tests green.
</objective>
