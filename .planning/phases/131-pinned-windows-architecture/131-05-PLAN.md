<objective>
Polish the TopBar pinned-window shelf with affordances expected of an OS-shaped feature:

1. **Hover preview**: hovering a chip for >500ms pops up a small thumbnail (screenshot for WebApp, snippet for AI Chat, path tree for Files).
2. **Drag-off unpin**: dragging a chip off the shelf onto the desktop unpins it and restores the window where it's dropped.
3. **Right-click menu**: Restore / Close / Toggle AI Control / Pin to a different position.
4. **Reorder**: drag chips horizontally within the shelf — order persists to `pinned_windows.position_in_shelf`.
5. **Empty-shelf hint**: nicer visual than the current "Drag here to pin" — show a subtle dashed area with a small chevron icon.
6. **Chip thumbnail caching**: thumbnails refresh every 30s while the chip is visible (livinityd snapshot endpoint).

Independent of Plan 131-03/04 — works against the persistence layer alone, gracefully degrades if no background runtime exists.
</objective>
