<objective>
Restyle Server5 `/store` (landing + sidebar + topbar + category sections + featured hero + app card + app detail + profile) to consume canonical design tokens.

**The store subtree is the largest in this phase (~13 TSX files per INVENTORY).** Strategy: split into two execution tasks — (Task 1) shell + landing, (Task 2) detail + profile + components. Task 3 builds + smoke-tests.

**Scope locks:**
- D-117-NO-API-CHANGES — `/api/apps/**` + `/api/store/**` route handlers untouched. `store-provider.tsx` (pure context plumbing, tagged wontfix in INVENTORY) is NOT in scope.
- D-117-NO-AUTH-FLOW-CHANGES — getSession / session cookie flow untouched.
- **Featured-hero gradient decision** (open question from CONTEXT.md `/store` is large; can it be sub-batched?): Phase 117-04 KEEPS the 13 per-category gradients as a deliberate "store branding" departure from dashboard.html, but **wraps them in token-aware utility classes** so a future phase can swap palettes without code edits. The 13 gradient presets get exported from a new `featured-hero-gradients.ts` constants file ONLY IF the existing file structure already has gradient consts inline — otherwise leave in place. Decision documented in 117-04-SUMMARY.md.

Purpose: Make the public app store visually match the canonical token system (Apple-grays out, dash tokens in) while preserving its slightly-distinct branded character (category gradients).
Output: 10 files restyled on Server5, gradient decision documented, pm2 restarted, /store routes smoke-tested.
</objective>

**Class map (Server5 store-specific extras on top of base map):**

```
# Apple-grays (per INVENTORY) → canonical
#e5e5e7  (border literal)           → border-dash-line          (use border-[color:var(--dash-line)])
#86868b  (muted text literal)       → text-[color:var(--muted-fg)]   (fallback: text-[color:rgba(0,0,0,0.55)])
bg-gray-100                         → bg-card-bg-2
bg-gray-50                          → bg-card-bg-2
text-gray-500                       → text-[color:var(--muted-fg)]
text-gray-700                       → text-[color:var(--fg)]

# App-card blue pill badges
bg-blue-50 text-blue-600            → bg-[color:rgb(37_99_235/0.08)] text-accent-blue
bg-blue-100                         → bg-[color:rgb(37_99_235/0.12)]

# Topbar (frosted glass — KEEP the frosted effect, swap colors)
bg-white/80 backdrop-blur-xl        → bg-[color:rgba(255,255,255,0.78)] dark:bg-[color:rgba(20,20,20,0.78)] backdrop-blur-xl
border-[#e5e5e7]                    → border-dash-line

# Bento card chrome
rounded-2xl                         → rounded-dash
shadow-md / shadow-lg               → shadow-card
border border-gray-200              → border border-dash-line
```
