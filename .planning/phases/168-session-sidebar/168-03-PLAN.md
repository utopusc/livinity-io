<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| activeSessionId React state → CcTerminal key+prop | In-process; not a security boundary, just a remount trigger. |
| `<SessionSidebar onSelect>` callback → activeSessionId state | In-process; sidebar may emit null (delete-of-active path) which renders empty-state. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-168-03-01 | T (Tampering via stale state) | activeSessionId persists across SessionSidebar refetches | accept | Polling refetch in 168-02 may surface sessions whose ids don't include current `activeSessionId` (e.g., deleted on another tab). CcTerminal will attempt to attach to a missing session and the server returns "session not found" — surfaced as a visible terminal error per Phase 167 contract. No data leak; degrades to a re-create flow. |
| T-168-03-02 | I (Info disclosure) via stale terminal output across session switch | CcTerminal remount on key change | mitigate | `key={activeSessionId}` triggers FULL unmount + remount, which per Phase 167's dispose contract closes the prior WS and creates a new one. No xterm buffer leak across sessions. |
| T-168-03-03 | I (Info disclosure) — activeSessionId in URL / localStorage | activeSessionId is in-process state only | accept | This plan does NOT persist activeSessionId to localStorage or URL. Even if a future plan adds persistence, session ids are not secrets (server-side userId-scoped 168-01 RBAC is the actual gate). |
| T-168-03-04 | E (Elevation) — placeholder regression sneaking through | grep invariant in done criteria | mitigate | Done criteria require ZERO matches of `Session sidebar — Phase 168` (the placeholder string). Any review/CI regression that accidentally restores the placeholder fails the assertion. |
| T-168-03-05 | E (Elevation) — sidebar mounted on mobile (skips fallback) | useIsMobile branch | mitigate | The `if (isMobile) return <FallbackCard>` early return is preserved verbatim. SessionSidebar never renders on mobile, so the touch-unfriendly UI never reaches mobile users. |
</threat_model>
