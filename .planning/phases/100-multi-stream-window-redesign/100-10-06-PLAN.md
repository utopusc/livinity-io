# Plan 100-10-06: Chat in-place response (action bar 3-mode state machine + Stop)

<objective>
The 09-08 plan shipped a 2-mode action bar (`'icons'` | `'chat-input'`) where Send/Enter sent the message AND immediately returned to `'icons'` mode (the chat response, if any, was visible elsewhere — but the user feedback in 100-10-CONTEXT issue 6 says the response should appear IN PLACE OF the input). Add a 3rd mode `'chat-response'` (D-100-10-E):

- Click Chat icon → `'chat-input'` (existing 09-08 behavior — input + Send + Close).
- Type + Enter (or click Send) → `sendMessage(text)` THEN flip mode to `'chat-response'`. Input area is REPLACED by a streaming response panel; the right-side button becomes Stop (calls `stopStreaming()`); Close (X) stays.
- During streaming, the response panel renders `messages.at(-1).content` with a streaming caret + light markdown rendering. Stop button is enabled.
- Click Stop → call `useWebAppAgent.stopStreaming()`. Response panel STAYS visible (frozen at the partial content); Stop button transitions to a "Send another" affordance OR Close (X) returns to `'icons'`.
- Stream completes → response stays visible; Stop transitions back to nothing (or a Close hint). User can click Close (X) → `'icons'`. Or type new prompt → flip back to `'chat-input'` (response cleared).
- Press Escape → `'icons'` (whether from input OR response).

Also verify `useWebAppAgent.stopStreaming()` exists. Today the hook exposes `interrupt: () => void` (line 60 + line 199 of `use-webapp-agent.ts`) — the plan exposes a NEW `stopStreaming` alias OR maps directly to `interrupt`. Decision: add `stopStreaming` as a thin alias that calls `interrupt()` — preserves the canonical name `interrupt` for back-compat AND gives the floating bar the literal `stopStreaming` identifier the CONTEXT specifies (`useWebAppAgent.stopStreaming()`).
</objective>

<must_haves>
- `ChatInputMode` type in `webapp-drawer-store.ts` extended from `'icons' | 'chat-input'` to `'icons' | 'chat-input' | 'chat-response'`.
- `webapp-floating-action-bar.tsx` renders a third branch `<ChatResponseBar/>` when mode is `'chat-response'` — same `motion.div` host with `layout` prop.
- `<ChatResponseBar/>` reads `messages` + `isStreaming` from `useWebAppAgent(webappId)`.
- `<ChatResponseBar/>` shows the latest assistant message text (`messages.findLast(m => m.role === 'assistant')?.content ?? ''`) with a streaming caret while `isStreaming === true`.
- Stop button visible during `isStreaming`; click → `agent.stopStreaming()`.
- After streaming completes, the right-side button transitions to a "New message" affordance OR Close (X) returns to `'icons'`. Decide: keep Close (X) always present; replace Stop with "New" icon when not streaming (clicking "New" → `'chat-input'` with response cleared). Implementer chooses based on what looks better — document the choice in the SUMMARY.
- `useWebAppAgent` hook exports `stopStreaming: () => void` (alias to `interrupt`).
- After ChatInputBar's Send/Enter, mode flips to `'chat-response'` (NOT `'icons'` — that's the 09-08 behavior we're SUPERSEDING).

```typescript
interface ChatResponseBarProps {
  webappId: string
  onClose: () => void   // X button → return to icons
  onNew: () => void     // "New message" affordance → back to chat-input with response cleared
}

function ChatResponseBar({webappId, onClose, onNew}: ChatResponseBarProps) {
  const agent = useWebAppAgent(webappId)
  const lastAssistant = useMemo(() => {
    for (let i = agent.messages.length - 1; i >= 0; i--) {
      if (agent.messages[i].role === 'assistant') return agent.messages[i]
    }
    return null
  }, [agent.messages])

  // Auto-bind Escape → onClose at window level (mirrors ChatInputBar).
  useEffect(() => {
    const onKey = (e: KeyboardEvent) => {
      if (e.key === 'Escape') {
        e.preventDefault()
        onClose()
      }
    }
    window.addEventListener('keydown', onKey)
    return () => window.removeEventListener('keydown', onKey)
  }, [onClose])

  return (
    <Magnetic intensity={0.2}>
      <div className='flex items-center gap-2 rounded-2xl bg-white/95 backdrop-blur-xl border border-neutral-200/60 shadow-[0_2px_8px_rgba(0,0,0,0.08)] px-4 py-3 max-w-[480px]'>
        <div className='flex-1 text-caption-sm text-text-primary whitespace-pre-wrap'>
          {lastAssistant?.content ?? ''}
          {agent.isStreaming ? (
            <span className='inline-block w-1.5 h-3.5 ml-1 bg-primary animate-pulse' aria-hidden='true' />
          ) : null}
        </div>
        {agent.isStreaming ? (
          <button
            type='button'
            onClick={() => agent.stopStreaming()}
            aria-label='Stop'
            className='flex h-7 w-7 items-center justify-center rounded-full bg-red-500 text-white hover:bg-red-600 transition-colors'
          >
            {/* Square icon for Stop */}
            <Square className='h-3.5 w-3.5' strokeWidth={2.25} />
          </button>
        ) : (
          <button
            type='button'
            onClick={onNew}
            aria-label='New message'
            className='flex h-7 w-7 items-center justify-center rounded-full bg-primary text-white hover:bg-primary/90 transition-colors'
          >
            {/* Plus icon */}
            <Plus className='h-3.5 w-3.5' strokeWidth={2.25} />
          </button>
        )}
        <button
          type='button'
          onClick={onClose}
          aria-label='Close chat response'
          className='flex h-7 w-7 items-center justify-center rounded-full text-neutral-500 hover:bg-neutral-100 hover:text-neutral-800 transition-colors'
        >
          <X className='h-3.5 w-3.5' strokeWidth={2.25} />
        </button>
      </div>
    </Magnetic>
  )
}
```
