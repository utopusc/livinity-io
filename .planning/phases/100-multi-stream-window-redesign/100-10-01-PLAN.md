# Plan 100-10-01: Per-WebApp Xvfb display allocator + lifecycle

<objective>
Each WebApp gets its OWN Xvfb display (`:10`, `:11`, `:12`...) plus its own fluxbox WM, instead of all WebApps sharing `:1` (D-100-10-A). At spawn time, allocate the next free display number, start Xvfb + fluxbox on it, and pass `DISPLAY=:N` into Chrome. At close time, kill Chrome + fluxbox + Xvfb on that display and release the display number for reuse. The per-window `x11vnc` argv changes from `-id 0xHEX` (single-window capture) to `-display :N` (whole-display capture) — this is what eliminates the ISSUE 2 black-overlap (each Chrome owns its display, no compositor stacking) and ISSUE 1 "Chrome itself" capture (whole-display capture sees Chrome's full pixels regardless of window state).
</objective>

<must_haves>
- A `DisplayAllocator` service exists with `allocate()` returning the next free display string (`:10` first call, `:11` second call) and `release(display)` returning it to the free pool.
- `window-manager.spawn()` calls `displayAllocator.allocate()` BEFORE Chrome spawn; spawns Xvfb + fluxbox on that display; passes `DISPLAY=:N` into Chrome's spawn env (replacing the global `:1`).
- `window-manager.close()` calls `fluxbox.stop()` then `xvfb.stop()` then `displayAllocator.release(display)` AFTER killing Chrome.
- `vnc-bridge.spawnVncForWindow()` accepts an optional `display` arg; when set, argv switches from `-id 0xHEX` to `-display :N` (whole-display capture).
- Existing 100-08-01 helpers (`startXvfb`, `startFluxbox`) accept the per-WebApp display arg and are unchanged in shape (already parametric on `display`).
- Sacred SHA `f3538e1d811992b782a9bb057d1b7f0a0189f95f` preserved across all commits.
</must_haves>

```typescript
/**
 * Phase 100-10-01 — DisplayAllocator (D-100-10-A).
 *
 * Allocates and releases X display numbers starting at :10. Per-WebApp
 * displays eliminate cross-window stacking (Issue 2) and let x11vnc
 * capture the entire display (Issue 1). Free numbers are reused before
 * climbing.
 */
import {EventEmitter} from 'node:events'

export interface DisplayAllocator extends EventEmitter {
  allocate(): string
  release(display: string): void
  inUse(): string[]
}

const BASE = 10  // ':10' first; ':11' second; ...

export function createDisplayAllocator(): DisplayAllocator {
  const allocated = new Set<number>()
  const ee = new EventEmitter() as DisplayAllocator
  ee.allocate = () => {
    let n = BASE
    while (allocated.has(n)) n++
    allocated.add(n)
    const display = `:${n}`
    ee.emit('display:allocated', {display})
    return display
  }
  ee.release = (display: string) => {
    const n = Number(display.replace(/^:/, ''))
    if (!Number.isFinite(n) || !allocated.has(n)) return
    allocated.delete(n)
    ee.emit('display:released', {display})
  }
  ee.inUse = () => Array.from(allocated).sort((a, b) => a - b).map((n) => `:${n}`)
  return ee
}
```
