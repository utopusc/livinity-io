# Plan 100-10-04: Luse stream management tools (create_stream + list_streams)

<objective>
Implement the stream-management portion of D-100-10-C: two new MCP tools `mcp__luse__create_stream` and `mcp__luse__list_streams` that let the agent spawn a fresh x11vnc on a given display + enumerate currently-active streams in the system. Because `create_stream` is a privilege-escalation surface (an LLM-controlled agent creating new network listeners), it is gated behind the Redis flag `liv:config:luse_can_create_streams` (G-100-10-E default `false` for production, `true` in dev). The tool is REGISTERED unconditionally so the schema is discoverable, but the handler reads the flag at call-time and rejects with `{isError: true}` when disabled. The `list_streams` tool has no such gate (it's read-only and reveals only the current user's streams via the existing `streamManager.listStreams({userId})` filter).
</objective>

<must_haves>
- Two new entries in `LUSE_TOOLS` array: `create_stream` and `list_streams` — each with valid Zod input schema + description.
- Two new handlers in `mcp/tools.ts` registered under names `mcp__luse__create_stream` and `mcp__luse__list_streams`.
- `create_stream` accepts `{display: string, port?: number}`; calls `streamManager.startStream({mode: 'vnc-window', target: {display}, userId})` (extending `target` to allow display-mode); returns `{streamId, wsUrl, port}`.
- `create_stream` reads Redis key `liv:config:luse_can_create_streams` at call-time; if not `'true'`, returns `{isError: true, content: [{type: 'text', text: 'Error: luse_can_create_streams disabled'}]}` (G-100-10-E).
- `list_streams` calls `streamManager.listStreams({userId})` (existing 99-03 surface) and returns the array — no privilege gate, scoped to caller's userId.
- `streamManager`'s discriminated `target` union accepts `{display: string}` alongside the existing `{wid: number}` (for vnc-window mode); when `display` is set, the spawn path uses `vnc-bridge`'s `-display :N` mode (already added in 100-10-01).
- Sacred SHA `f3538e1d811992b782a9bb057d1b7f0a0189f95f` preserved across all commits.
</must_haves>

**Step 3 — Add 2 handlers in `mcp/tools.ts`.** Extend `LuseToolsOptions` to require `streamManager: StreamManager`, `redis: Redis`, `userId: string`. Then in the handler-map:

```typescript
'mcp__luse__create_stream': async (args: {display: string; port?: number}) => {
  // G-100-10-E privilege gate — fail-closed by default.
  let canCreate = false
  try {
    canCreate = (await options.redis.get('liv:config:luse_can_create_streams')) === 'true'
  } catch {
    canCreate = false  // Redis unavailable → deny.
  }
  if (!canCreate) {
    return {
      content: [{type: 'text', text: 'Error: luse_can_create_streams disabled (set Redis liv:config:luse_can_create_streams=true to enable)'}],
      isError: true,
    }
  }
  try {
    const result = options.streamManager.startStream({
      mode: 'vnc-window',
      target: {display: args.display},
      userId: options.userId,
    })
    return {
      content: [{type: 'text', text: JSON.stringify({streamId: result.streamId, wsUrl: result.wsUrl})}],
      isError: false,
    }
  } catch (err) {
    return {
      content: [{type: 'text', text: `Error: ${(err as Error).message ?? String(err)}`}],
      isError: true,
    }
  }
},

'mcp__luse__list_streams': async () => {
  try {
    const records = options.streamManager.listStreams({userId: options.userId})
    return {
      content: [{type: 'text', text: JSON.stringify(records)}],
      isError: false,
    }
  } catch (err) {
    return {
      content: [{type: 'text', text: `Error: ${(err as Error).message ?? String(err)}`}],
      isError: true,
    }
  }
},
```
