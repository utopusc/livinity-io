## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-255-12 | Information disclosure | popover rendering a foreign user's screenshot/VNC | mitigate | Authorization is enforced SERVER-side: displays.screenshot (plan 02) and getVncUrl (254-06) both gate on canAccessDisplay. The client cannot bypass it; a FORBIDDEN response simply yields no thumbnail/window. No client-side trust. |
| T-255-13 | Information disclosure | opening N live RFB sockets exposing more attack surface + perf | mitigate | D-255-THUMBS-SCREENSHOT: popover uses screenshot polling only; the contract test asserts no `RFB(`/`new WebSocket(` in displays-popover.tsx. Live VNC only on explicit card click. |
| T-255-14 | DoS | screenshot poll storm from many open cards | accept | Polls gated on `enabled: open` (zero requests when popover closed) + 2s interval + server-side 10s capture timeout. Single-tenant operator box; revisit only under multi-tenant load. |
