### Task 1 — Extend install-liv-assistant.sh with Step 238-C (footer URL redirect)

Block shape:
```bash
# ---------------------------------------------------------------------------
# Phase 238.1 Step C — Footer URL redirect (iOfficeAI/* -> livinity.io)
#
# Phase 234-03's case-sensitive sed `s/AionUi/Liv AI/g` literally rewrote
# vendored AionUi footer URLs from `https://github.com/iOfficeAI/AionUi/wiki`
# into `https://github.com/iOfficeAI/Liv AI/wiki` -- with a literal SPACE
# breaking the URL AND still pointing at the upstream org. Operator surfaced
# this 2026-05-27 evening: 5 footer links (Yardım Dokümantasyonu / Güncelleme
# Günlüğü / Sorun Bildir / Bana Ulaşın / Resmi Web Sitesi) all need to
# redirect to Livinity.
#
# Blanket pattern: `https://github.com/iOfficeAI/<anything-non-quote>` ->
# `https://livinity.io`. Covers all known variants:
#   - https://github.com/iOfficeAI/Liv AI/wiki   (helpDocumentation, broken)
#   - https://github.com/iOfficeAI/Liv AI        (officialWebsite, contactMe)
#   - https://github.com/iOfficeAI/AionHub       (index-BBQOKL1b, AionHub link)
# All 8+ affected files become a single Livinity homepage redirect.
#
# Idempotency: grep pre-check skips when no iOfficeAI URLs remain; post-grep
# verify warns if any survive. Pipefail wrap per Phase 238 hot-fix precedent
# (set +o pipefail around the grep+wc command substitutions).
#
# D-V43-APACHE-NOTICE: scope is ${REBRAND_TARGET}=${CURRENT_LINK}/static/,
# LICENSE + NOTICE structurally outside.
# ---------------------------------------------------------------------------
if [[ -d "${REBRAND_TARGET}" ]]; then
  set +o pipefail
  IO_PRE_HITS="$(grep -rilE 'https?://github\.com/iOfficeAI/' "${REBRAND_TARGET}" \
    --include='*.html' --include='*.js' --include='*.css' 2>/dev/null | wc -l)"
  set -o pipefail
  if [[ "${IO_PRE_HITS}" -gt 0 ]]; then
    log "Footer redirect: applying iOfficeAI/* -> livinity.io sed pass on ${IO_PRE_HITS} files"
    # Sed pattern: match the literal URL prefix + the path-tail charset that
    # includes the broken-space variant from Phase 234-03 collateral.
    # Charset [A-Za-z0-9 ._/-] keeps the SPACE intentionally to catch the
    # `Liv AI/wiki` variant. The + quantifier is greedy but JS minified
    # bundles keep URLs inside quoted strings, so the next non-charset char
    # is a quote/backtick which terminates the match cleanly.
    find "${REBRAND_TARGET}" \( -name '*.html' -o -name '*.js' -o -name '*.css' \) \
         -exec sed -E -i 's|https?://github\.com/iOfficeAI/[A-Za-z0-9 ._/-]+|https://livinity.io|g' {} +
    set +o pipefail
    IO_POST_HITS="$(grep -rilE 'https?://github\.com/iOfficeAI/' "${REBRAND_TARGET}" \
      --include='*.html' --include='*.js' --include='*.css' 2>/dev/null | wc -l)"
    set -o pipefail
    if [[ "${IO_POST_HITS}" -ne 0 ]]; then
      log "WARN: ${IO_POST_HITS} files still contain iOfficeAI/* URLs after redirect sed pass (investigate)"
    else
      log "Footer redirect: all iOfficeAI/* URLs rewritten to livinity.io (verified by post-grep)"
    fi
  else
    log "Footer redirect: no iOfficeAI/* URLs found (already redirected or absent); skipping"
  fi
else
  log "Footer redirect: WARN ${REBRAND_TARGET} missing; skipping"
fi
```

Verify with `bash -n scripts/install-liv-assistant.sh`.

## Known limitation (documented, NOT fixed in this phase)

The 24 Built-in skills shown in **Liv AI → Settings → Skills** tab (e.g. `aionui-skills`, `aionui-webui-setup`, `openclaw-setup`, `star-office-helper`) have NAMES and DESCRIPTIONS baked into the AionUi 2.1.4 Bun binary. Phase 234-03 deliberately excludes the 94MB binary from sed-rebrand to prevent ELF corruption (per `234-01-INVESTIGATION.md` Section F.5). Rebranding these requires either:

1. **Upstream fork** — out of scope per D-V42-SACRED ("vendor-and-wrap, no source fork").
2. **JS-injection via Caddy `sub`/`replace`** — feasible but complex; injects a `<script>` block into the iframe HTML that walks the DOM at runtime to rewrite skill name text nodes. Phase 232's `livinity-overlay.css` is the precedent for CSS-side injection; a JS variant would extend it. Could be a future phase if operator requirement persists.
3. **Hide the Skills tab via CSS** — operator loses access to a feature.

Decision deferred to operator. Documented here so future Claude session knows the constraint.
