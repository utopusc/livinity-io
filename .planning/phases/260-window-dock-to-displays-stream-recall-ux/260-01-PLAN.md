<objective>
Fix SC1: apps get stuck showing "uninstalling" / "restarting" in the grid forever. The
`app.state` field is in-memory (app.ts:61, default `'unknown'`); `restart()` sets `'restarting'`
then `'ready'` and `uninstall()` sets `'uninstalling'` with no try/finally, so a throw or a
livinityd restart mid-flight wedges the field. The admin/single-user `apps.state` query
(routes.ts:269-274) returns the raw field with NO Docker reconciliation, so the grid renders a
perpetual sliding-loader (the state is in `progressStates`, trpc.ts:127-128) and `handleAppClick`
treats the tile as un-clickable.

Purpose: Make transient app states self-heal so tiles never wedge.
Output: Docker-reconciled `apps.state` + try/finally-hardened lifecycle + a unit test.
</objective>
