## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| installer apt → host package state | installer fetches + installs packages from the host's configured apt mirrors (already trusted by the OS) |
| Luse MCP child → display-manager | the agent-driven MCP tool triggers display spawns; a missing-binary path must not lie about success |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-252-01 | Spoofing/Repudiation | display-manager create() false-success | mitigate | R3 fail-closed: no Redis key + isError:true on spawn error — downstream consumers cannot mistake a dead display for a live one |
| T-252-02 | Tampering | apt package list | accept | packages installed from the host's existing trusted apt mirrors; no new repo/key added; `|| warn` keeps a tampered/unavailable mirror non-fatal |
| T-252-03 | Denial of Service | apt block failure aborts install | accept | each apt group ends in `|| warn ... (non-fatal)` so a missing package cannot abort the install run |
</threat_model>
