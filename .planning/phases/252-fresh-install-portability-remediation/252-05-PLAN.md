<objective>
Env + seed hardening so the Luse stack resolves Redis + a valid X session on a fresh box without
the hand-made artifacts the live Mini PC accumulated. (R5) `liv-assistant.service` ships with no
EnvironmentFile, so aioncore→claude→luse children inherit no REDIS_URL — add a tolerant
`EnvironmentFile=-/opt/livos/.env`. (R6) the luse MCP seed bakes `XAUTHORITY=/run/user/1000/gdm/Xauthority`

substitution placeholders resolved at seed time. (R12) an empty `liv:mcp:config` catalog currently
warn-logs and silently no-ops — surface it as an operator-visible health signal.

Purpose: fresh-box Luse gets a working Redis URL + valid X env, and a missing MCP seed is loud, not invisible.

</objective>
