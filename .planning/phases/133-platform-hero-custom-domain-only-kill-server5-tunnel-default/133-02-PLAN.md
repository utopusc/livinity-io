Fix Bug B: dashboard hero hard-codes `${username}.livinity.io` as the
user's computer URL regardless of any custom_domain they've configured.

Fix in two parts:
1. **Patch `dashboard.html`** to derive `url` from `custom_domains`
   loaded via the existing `/api/account/domains` (or equivalent)

   install-pending empty state — do NOT fall back to tunnel URL.

   into `custom_domains` with status='active' so her hero immediately
   shows her real install (since 133-01's wizard fix only helps
   FUTURE Generate runs, not lucylu's already-completed install).

`autonomous: false` because the operator must supply lucylu's chosen
domain string (it's not recoverable from any platform state).
</objective>
