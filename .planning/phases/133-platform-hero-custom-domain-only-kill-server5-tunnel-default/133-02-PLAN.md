Patch `/opt/landing/livinity.io/dashboard.html` to derive the hero URL
from active custom_domains, with install-pending empty state fallback.

Replace line ~707:

```js
// BEFORE
const url = username + ".livinity.io";
```

With:

```js
// AFTER (Phase 133-02)
// Hero URL derives from custom_domains ONLY. No tunnel fallback —
// Server5 tunnel relay is being retired from user-visible surfaces.
const activeDomain = (domains || [])
  .filter(d => d && (d.status === "active" || d.status === "dns_verified"))
  .sort((a, b) => (b.verified_at || "").localeCompare(a.verified_at || ""))[0];
const url = activeDomain ? activeDomain.domain : null;
const hasComputer = !!url;
```

Then update the hero JSX block (~lines 720-770) to render two
branches based on `hasComputer`:

**`hasComputer === true`** (existing rendering, unchanged except
`href={"https://" + url}` already works since url is the real domain).

**`hasComputer === false`** (NEW empty state):

```jsx
<div className="hero-card empty">
  <div className="greet-mark"/>
  <h1 className="hero-title">Hey, <em>{username}.</em><br/>let's connect your computer.</h1>
  <p className="hero-sub">Finish your install to see your computer's URL here.</p>
  <div className="hero-cta-row">
    <a className="h-btn solid" href="/dashboard/install">
      Go to install wizard <Ic.arrow/>
    </a>
    <a className="h-btn" href="/profile">Profile</a>
  </div>
</div>
```
