# Plan 204-01 — Backend: provider.config.* tRPC + Redis + env-file writer + restart hook

## Objective

Build the server-side surface backing the new `/settings → Providers` tab:

1. A factory-DI tRPC router `provider.config.{list,set,delete}` (adminProcedure-gated).
2. A Redis-backed key store with redacted-on-read semantics.
3. An env-file writer that emits `/etc/default/liv-claw-gateway` (or fallback path) atomically.
4. A `sudo systemctl restart liv-claw-gateway` hook with EACCES-resilient fallback to a "restart-required" flag.
5. Three vitest files exercising the boundaries.

All wired into livinityd's boot wire-up alongside `mcpConfig` + `openclawosApps`.

## Tasks

### Task 1 — `provider/key-store.ts` (Redis CRUD helper)

**Type:** auto

**File to create:** `livos/packages/livinityd/source/modules/provider/key-store.ts`

**Behavior:**
- Class `ProviderKeyStore` wrapping ioredis. Methods:
  - `async set(provider: ProviderName, key: string): Promise<void>` — HSET `liv:provider:keys` field=provider value=JSON.stringify({key, addedAt: new Date().toISOString()}).
  - `async get(provider: ProviderName): Promise<{key: string; addedAt: string} | null>` — HGET + JSON.parse + defensive null-on-corrupt (logs warn, returns null).
  - `async delete(provider: ProviderName): Promise<boolean>` — HDEL; returns true if a field was removed.
  - `async list(): Promise<Array<{provider: ProviderName; preview: string; addedAt: string}>>` — HGETALL → map to redacted shape. Sort alphabetically by provider name. **NEVER returns the raw key.**
  - `async getAllForEnvFile(): Promise<Record<string, string>>` — INTERNAL ONLY (used by env-file writer; not exposed via tRPC). Returns `{XAI_API_KEY: 'xai-...', ANTHROPIC_API_KEY: '...'}` shape.
- Helper `redactKey(provider, key) → "<provider>-***<last4>"`.
- Export const `PROVIDER_ENUM = ['xai','anthropic','openai','groq','mistral','ollama'] as const` + type `ProviderName = (typeof PROVIDER_ENUM)[number]`.
- Export const `PROVIDER_ENV_VAR: Record<ProviderName, string>` = `{xai:'XAI_API_KEY', anthropic:'ANTHROPIC_API_KEY', openai:'OPENAI_API_KEY', groq:'GROQ_API_KEY', mistral:'MISTRAL_API_KEY', ollama:'OLLAMA_API_KEY'}`.
- Logger lines: NEVER include raw key. Always `[provider-key-store] set ${provider} (preview=${redactKey(provider, key)})`.

**Done criteria:**
- TypeScript compiles cleanly under `pnpm --filter livinityd build` (best-effort `tsc --noEmit` smoke is acceptable since livinityd runs via tsx — but the file MUST type-check).
- vitest file (Task 4) green.

### Task 2 — `provider/env-file-writer.ts` (regen + chmod 0600 + EACCES fallback)

**Type:** auto

**File to create:** `livos/packages/livinityd/source/modules/provider/env-file-writer.ts`

**Behavior:**
- Class `EnvFileWriter`. Constructor `{keyStore: ProviderKeyStore, logger}`.
- Method `async sync(): Promise<{path: string; mode: number}>`:
  1. Call `keyStore.getAllForEnvFile()` to get the full env map.
  2. Build the file body: `# Generated by livinityd Plan 204-01 — do not edit by hand\n# Last sync: <ISO>\n` + sorted `KEY=VALUE\n` lines.
  3. Try writing atomically (write to `<path>.tmp` then rename) to `/etc/default/liv-claw-gateway` with mode 0600.
  4. On EACCES (or EPERM) try the same atomic write to `/opt/livos/etc/liv-claw-gateway.env` (mkdir -p with 0700; chmod 0600 on the file).
  5. Return the chosen `{path, mode}`.
- Method `async readChosenPath(): Promise<string>` — reads `liv:provider:env-file-path` from Redis (set after first successful sync) so the same path is preserved across restarts.
- Pure-function helper `formatEnvFile(map: Record<string,string>, timestamp: string): string` — exported for unit-tests.
- Validation: every value MUST match `/^[A-Za-z0-9_\-\.]{8,500}$/`. Reject (throw `Error('INVALID_KEY_FORMAT')`) BEFORE write. Defense-in-depth — the tRPC layer also validates (T-204-04).

**Done criteria:**
- vitest file (Task 4) verifies: correct shape, chmod 0600, EACCES fallback path, INVALID_KEY_FORMAT throw, idempotent re-write.

### Task 3 — `provider-config-router.ts` + boot wire-up + common.ts entry

**Type:** auto

**Files to create:**
- `livos/packages/livinityd/source/modules/server/trpc/provider-config-router.ts`

**Files to modify:**
- `livos/packages/livinityd/source/modules/server/trpc/common.ts` (add `provider.config.list`, `provider.config.set`, `provider.config.delete` to `httpOnlyPaths`)
- `livos/packages/livinityd/source/modules/server/trpc/index.ts` (import + factory slot + namespace mount)
- `livos/packages/livinityd/source/index.ts` (boot wire-up — construct factory with real deps)

**Behavior — router:**
- Pattern: empty-injection stub + `createProviderConfigRouter({keyStore, envFileWriter, restartHook, logger})` factory (mirror `createMcpConfigRouter`).
- Three adminProcedure routes:
  - `list` → query. Calls `keyStore.list()` and returns `{providers: Array<{provider, preview, addedAt}>}`.
  - `set` → mutation. Input `{provider: z.enum(PROVIDER_ENUM), key: z.string().regex(/^[A-Za-z0-9_\-\.]{8,500}$/, 'INVALID_KEY_FORMAT')}`. Flow:
     1. `keyStore.set(provider, key)`
     2. `envFileWriter.sync()` → captures path
     3. `restartHook()` → returns `{ok: boolean; reason?: string}` (false means sudo failed; truthy `restartRequired` surfaced in response)
     4. Returns `{ok: true, envFilePath, restartTriggered: restartHook.ok, restartRequired: !restartHook.ok}`
  - `delete` → mutation. Input `{provider: z.enum(PROVIDER_ENUM)}`. Same flow minus the keyStore.set step.
- Logger lines: `[provider-config] set ${input.provider} (preview=${redactKey(...)})` — NEVER the raw key. Same for delete (no preview, just provider name).

**Behavior — restartHook (separate helper):**
- Create `livos/packages/livinityd/source/modules/provider/restart-hook.ts` exposing `createRestartHook({logger})` returning `async () => Promise<{ok: boolean; reason?: string}>`.
- Use `child_process.execFile('sudo', ['/bin/systemctl', 'restart', 'liv-claw-gateway'], {timeout: 10_000})`.
- On non-zero exit OR exec error → return `{ok: false, reason: stderr || 'sudo unavailable'}`. Log warn (NEVER throw — restart failure is a graceful-degradation path).

**Behavior — common.ts:**
- Add at end of array (next to openclawos.apps.*):
  ```ts

  // LLM provider API key entry flow. set/delete trigger sudo systemctl restart
  // liv-claw-gateway and a 30s health poll. All 3 paths route via HTTP for the
  // same WS-reconnect-survival rationale as the rest of the admin cluster
  // (mcp.config.* line ~358, agents.* line ~303). Pitfall B-12 / X-04.
  'provider.config.list',
  'provider.config.set',
  'provider.config.delete',
  ```

**Behavior — index.ts (trpc):**
- Import `createProviderConfigRouter, providerConfigRouter`.
- Add `providerConfig?: ReturnType<typeof createProviderConfigRouter>` to `createAppRouter` opts.
- Mount as `provider: router({config: opts.providerConfig ?? providerConfigRouter})` (NEW top-level `provider` namespace — INV-204-08 preserved).

**Behavior — source/index.ts (boot wire-up):**

### Task 4 — Three vitest files (key-store + env-file-writer + provider-config-router)

**Type:** auto

**Files to create:**
- `livos/packages/livinityd/source/modules/provider/key-store.test.ts` (6 cases)
- `livos/packages/livinityd/source/modules/provider/env-file-writer.test.ts` (4 cases — uses temp dir + simulated EACCES via wrapper)
- `livos/packages/livinityd/source/modules/server/trpc/provider-config-router.test.ts` (5 cases — empty-injection stub + 4 happy/sad paths)

**Test cases — key-store:**
1. `set(xai, 'xai-abc12345')` then `get(xai)` returns `{key: 'xai-abc12345', addedAt: <ISO>}`.
2. `list()` after setting xai returns `[{provider: 'xai', preview: 'xai-***2345', addedAt: <ISO>}]` — preview ends in last 4 chars, raw key NOT in response.
3. `delete(xai)` returns true; subsequent `get(xai)` returns null.
4. `get(anthropic)` on empty store returns null (no throw).
5. `set(xai, 'old12345')` then `set(xai, 'new12345')` → `get(xai).key === 'new12345'` AND addedAt is the second timestamp (overwrites, doesn't merge).
6. Preview format: `redactKey('groq', 'gsk_abcdefgh') === 'groq-***efgh'`.

**Test cases — env-file-writer:**
1. With keys `{xai: 'xai-aaaa1234', groq: 'gsk_bbbb5678'}`, `formatEnvFile` output contains lines `XAI_API_KEY=xai-aaaa1234\n` and `GROQ_API_KEY=gsk_bbbb5678\n` sorted alphabetically by env-var name.
2. Sync to a tmp path; verify `fs.statSync(path).mode & 0o777 === 0o600`.
3. Sync to `/root/forbidden/path` (synthetic EACCES) → falls back to second path provided in constructor; returned `{path}` is the fallback path.
4. `formatEnvFile({}, '<ts>')` is idempotent: same input → byte-identical output.

**Test cases — provider-config-router:**
1. Empty-injection stub `providerConfigRouter.list()` throws `PRECONDITION_FAILED` + `PROVIDER_CONFIG_UNAVAILABLE`.
2. Built router `list()` → `[]` when store is empty.
3. Built router `set({provider: 'xai', key: 'xai-validkey1234'})` → calls keyStore.set + envFileWriter.sync + restartHook in that order (assert with mock invocations).
4. Built router `set({provider: 'xai', key: 'short'})` → zod rejects with INVALID_KEY_FORMAT (length < 8).
5. Built router `set({provider: 'unknown' as any, key: 'xai-validkey1234'})` → zod rejects (BAD_REQUEST).

**Done criteria:**
