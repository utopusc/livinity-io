  goose         → curl -fsSL https://github.com/block/goose/releases/download/stable/download_cli.sh | CONFIGURE=false bash

                  → binary `cursor-agent` → ~/.local/bin (installer ALSO creates a bare `agent` symlink — probe cursor-agent, NOT agent)
                  (GOTCHA: Mar-2026 installer had a 403 on asset download — if installer fails at runtime the script must fail cleanly with code 75, not silently pass)

Locked conventions (RESEARCH Pattern 2):
  export PATH="${HOME}/.local/bin:/usr/local/bin:${PATH}" BEFORE idempotency probe
  idempotency: command -v <bin> >/dev/null 2>&1 && { ok "..."; exit 0; }
  after install: re-export ~/.local/bin, hash -r, re-verify command -v <bin> (fail 75 if missing)
  .profile marker: same idempotent 'LivOS CLI PATH' grep-guard append as Wave A
