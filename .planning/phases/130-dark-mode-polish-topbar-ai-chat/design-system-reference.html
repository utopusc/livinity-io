Livinity Design System — A to Z

Tokens, type, components, motion and the editorial decisions behind every screen on livinity.io. Use this as the spec sheet when porting designs into the livos React/Tailwind app.

00 · Foundation

Apple-restrained, editorial, monochrome by default.

Livinity feels like a calm operating system, not a SaaS site. The aesthetic borrows from Apple's marketing pages (typographic hierarchy, system fonts, generous whitespace, single accent), Linear's product chrome (sharp neutrals, hairline borders), and Stripe-style editorial (italic serif accents for warmth).

Do

One accent. One voice. Real whitespace.

Use the foreground (near-black) as the only accent. Let layout breathe with clamp() padding. Reach for an italic serif only to humanize a number or a headline — never for body.

Don't

No gradients, no glow, no emoji.

The single permitted gradient is the avatar (warm peach→pink). Hover transforms are subtle (translateY 2–3px, opacity .88). Iconography is 1.5px stroke, lucide-style, monochrome.

Mental model. Pretend every screen is a page in a printed Apple keynote book: a section eyebrow in mono, a thin display headline, a paragraph of body, then content. If a screen feels boring it's almost always under-designed — add an italic serif word, a hairline, or a mono caption instead of color.

The italic-serif rule. Exactly one italicized word per headline, placed where you'd put emphasis with your voice ("Account & identity"). Never two. Never in body. This is the single most identifiable typographic move in the brand.
03 · Rhythm

Spacing is fluid. Radii are soft.

Section padding uses clamp() so the breathing scales with viewport. Radii are quantized — 8/12/14/18/22/28 — pick the matching tier for the component's size.

04 · Components

Two buttons, two sizes, one motion.

Pill radius on everything. Primary inverts fg/bg, ghost uses hairline border. Hover lifts 1px and dims opacity to 0.88. No filled-color buttons exist.

Buttons hover: translateY(-1px) · opacity .88 · 250ms ease-out
.btn {
  display: inline-flex; align-items: center; gap: 8px;
  padding: 11px 20px; border-radius: 999px;
  font-weight: 500; font-size: 14px; letter-spacing: -0.005em;
  border: 1px solid transparent;
  transition: opacity .2s, background .25s, transform .25s var(--ease-out);
}
.btn:hover { transform: translateY(-1px); }
.btn-primary { background: var(--fg); color: var(--bg); }
.btn-primary:hover { opacity: .88; }
.btn-ghost   { background: transparent; color: var(--fg); border-color: var(--line-strong); }
.btn-ghost:hover { background: var(--bg-2); }

18 · Motion

Movement is restrained.

Three easings, three durations. Hover is a 1–3px lift, never a scale. Page-entry animations are blur-from + translate (8px), 600–800ms, one-shot. Reduced-motion always honored.

Easings 
--ease-out:    cubic-bezier(.2, .7, .2, 1)  // default
--ease-in-out: cubic-bezier(.4, 0, .2, 1)
// linear → only for marquee tickers + carets
Durations 
hover            200–250ms
content reveal   600–800ms
hero entry       1000–1600ms (one-shot only)
marquee          38–50s linear infinite
breathing dots   1.6–2.4s ease-in-out infinite
Patterns

Common keyframes you'll reuse.

/* Page entry — every section the user scrolls to */
@keyframes fadeUp {
  from { opacity: 0; transform: translateY(8px); filter: blur(6px); }
  to   { opacity: 1; transform: translateY(0);   filter: blur(0); }
}

/* Status pulse — used on .live, online dots, ready states */
@keyframes pulseDot {
  0%,100% { box-shadow: 0 0 0 0 rgba(34,197,94,.6); }
  50%     { box-shadow: 0 0 0 6px rgba(34,197,94,0); }
}

/* Wave — only on greeting emoji */
@keyframes wave {
  0%,60%,100% { transform: rotate(0); }
  10%,30%     { transform: rotate(14deg); }
  20%         { transform: rotate(-8deg); }
}

/* ALWAYS guard with reduced-motion */
@media (prefers-reduced-motion: reduce) {
  * { animation: none !important; transition: none !important; }
}
19 · Theming

Dark mode is literal inversion + a glow allowance.

Body gets a .dark class. All tokens swap. Cards and tiles gain a subtle white outer glow on hover (only in dark) because the missing shadow on near-black surfaces needs a tactile cue.

Light

A calm working surface.

--bg #fff · --bg-2 #f5f5f7 · --fg #1d1d1f

Dark

Identical hierarchy, inverted.

--bg #0a0a0c · --bg-2 #14141a · --fg #f5f5f7

Mode parity in dark, .card:hover gets box-shadow: 0 0 60px -10px rgba(255,255,255,.30)
20 · Port guide

Wiring this into your livos Tailwind config.
