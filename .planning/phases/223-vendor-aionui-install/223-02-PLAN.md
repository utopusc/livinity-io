Create `systemd/liv-assistant.service` with mode 0644 and EXACT content below:

```ini
[Unit]
Description=Liv Assistant (AionUi WebUI, vendored v2.1.4)
Documentation=file:///opt/liv-assistant/UPSTREAM.md
Documentation=https://github.com/iOfficeAI/AionUi
After=network-online.target
Wants=network-online.target

[Service]
Type=simple
User=bruce
Group=bruce
WorkingDirectory=/opt/liv-assistant/current
Environment="PATH=/home/bruce/.bun/bin:/usr/local/bin:/usr/bin:/bin"
Environment="HOME=/home/bruce"
ExecStart=/opt/liv-assistant/current/aionui-web start --port 3020 --data-dir /opt/liv-assistant/data --backend-bin /opt/liv-assistant/current/bundled-aioncore/linux-x64/aioncore
Restart=on-failure
RestartSec=5
StandardOutput=journal
StandardError=journal
SyslogIdentifier=liv-assistant

# Hardening (minimal — keep aionui's HTTP listener + claude CLI spawn working)
NoNewPrivileges=false
ProtectSystem=full
ProtectHome=read-only
ReadWritePaths=/opt/liv-assistant/data /home/bruce/.claude /home/bruce/.bun /home/bruce/.cache

[Install]
WantedBy=multi-user.target
```

**Rationale for each non-obvious choice:**

- `User=bruce` (NOT root) — Claude Code ACP bridge reads `/home/bruce/.claude/.credentials.json` (subscription token); aioncore must run as bruce to inherit that auth context (per 222-SPIKE.md Q3 evidence).
- `Environment="PATH=..."` — explicitly prepends `/home/bruce/.bun/bin` because systemd's default PATH does NOT include user-local bun install. Without this, the Claude Code agent spawns `bun x ...` and fails ENOENT. This is THE critical PATH fix from 222-SPIKE.md "Risks surfaced" #3.
- `Environment="HOME=/home/bruce"` — bun's runtime resolution + `~/.claude/` access need HOME set; systemd doesn't set it by default for User= services.
- ExecStart uses absolute paths (not `./aionui-web`) — systemd resolves WorkingDirectory but it's safer/more debuggable to be explicit. WorkingDirectory is `/opt/liv-assistant/current` (symlink → `aionui-web-2.1.4/aionui-web/`) so data files written relative to CWD land in the right place.
- `ProtectHome=read-only` + `ReadWritePaths=/home/bruce/.claude /home/bruce/.bun /home/bruce/.cache` — bun needs to write to its cache (npm package downloads for the ACP shim), claude CLI may rotate its token, but we don't grant generic /home/bruce write. This is defense-in-depth, not a hard requirement; if bun needs additional write paths during operator UAT in Plan 05, expand ReadWritePaths.
- `NoNewPrivileges=false` — bun + claude CLI may need to fork+exec subprocesses (e.g. shell-out tools). Keeping this off matches OpenClawOS service posture. Revisit in Phase 228 threat model.
- Port `3020` — chosen because spike confirmed nothing on Mini PC listens there (live `docker ps` clean during 222). Validated again by Plan 05 deploy preflight.
