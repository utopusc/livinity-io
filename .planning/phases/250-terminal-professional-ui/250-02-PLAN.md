## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user input → SearchAddon regex | a malicious/expensive regex from the find input could cause ReDoS in the search |
| PTY output → highlight decorations | searched content originates from the shell stream |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-250-02-01 | Denial of service | regex find over large buffer | mitigate | rely on addon `highlightLimit` (default 1000) + debounced incremental search; regex runs client-side only against the local buffer (no server impact) |
| T-250-02-02 | Tampering | dependency supply chain (new dep) | mitigate | pin `^0.15.0` (first-party @xterm scope), `pnpm install` lockfile committed; verify peer resolves to xterm 5.x |
| T-250-02-03 | Information disclosure | search reads scrollback | accept | scrollback is the operator's own session output, already visible in the same pane |
</threat_model>
