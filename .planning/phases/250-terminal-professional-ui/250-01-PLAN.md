## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| terminal output → WebLinks parser | PTY stream is rendered; a malicious URL in output could be auto-opened |
| browser tab → window.open | opened external page could attempt window.opener tampering |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-250-01-01 | Tampering | WebLinksAddon opened page | mitigate | `window.open(uri,'_blank','noopener,noreferrer')` — opened page cannot reach `window.opener` |
| T-250-01-02 | Elevation | accidental link navigation from PTY output | mitigate | open ONLY on Ctrl/Cmd-click (modifier required), never on plain click |
| T-250-01-03 | Information disclosure | theme/ergonomics constants | accept | client-side cosmetic constants, no secrets, no PII |
</threat_model>
