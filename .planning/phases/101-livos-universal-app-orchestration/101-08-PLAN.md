<objective>
Replace the current interval-driven teach recorder with the SelfClaude action-driven pattern (verified by 101-RESEARCH.md Pattern 3 + GitHub source). User clicks inside the streamed window → noVNC canvas DOM `mousedown` (capture phase) records the click → 100ms later an instruction popover anchored at the click point pops up → user types "Bu adımı ne için yapıyorsun?" → Save commits the step into a v3 action log. Backend `skill_replay_tool.ts` gains a v3 branch that replays steps with the instruction text logged on drift. v2 skills still replay via the existing lazy-translation shim (D-100-10-I).

Per the PATTERNS.md risk note (point 3 in orchestrator instructions), `webapps/teach-recorder.ts` does NOT exist at the livinityd backend path. The recorder is the UI hook `livos/packages/ui/src/hooks/use-teach-recorder.ts`. This plan extends the UI hook in place; backend only receives the finalized `ActionLogV3` via the existing skill-save tRPC mutation. NO new CDP work is needed — SelfClaude's pattern is purely UI-tier DOM listeners on the noVNC canvas (RESEARCH correction #3 / orchestrator correction 1b).

This plan depends on Wave 0 (`101-00`) for the test-stub scaffolding (`teach-popover.test.tsx`, `webapp-teach-popup-host.test.tsx`).

Purpose: Pillar D — replace the bad "screen recording" UX with explicit, intent-tagged step recording. Each step carries the user's own instruction, which is exactly what enables Phase 102 drift-recovery via vision.

<!-- pushClick + onAfterClick pattern (RESEARCH.md lines 510-530 verbatim): -->
```typescript
function pushClick(ev: MouseEvent) {
  if (!active) return
  const canvas = active.canvas
  const rect = canvas.getBoundingClientRect()
  if (!rect.width || !rect.height) return
  const scaleX = canvas.width / rect.width
  const scaleY = canvas.height / rect.height
  const x = Math.max(0, Math.min(canvas.width - 1, Math.round(ev.offsetX * scaleX)))
  const y = Math.max(0, Math.min(canvas.height - 1, Math.round(ev.offsetY * scaleY)))
  let button: 1 | 2 | 3
  if (ev.button === 0) button = 1
  else if (ev.button === 2) button = 3
  else button = 2
  active.events.push({type: 'click', button, x, y, ts: Date.now()})
  if (active.onAfterClick) {
    const cb = active.onAfterClick
    setTimeout(() => {
      try { cb({x, y, button}) } catch (e) { console.error('[teach-recorder] onAfterClick threw', e) }
    }, 100)
  }
}
```

       ```typescript
       import {useEffect, useMemo, useState} from 'react'
       import * as Popover from '@radix-ui/react-popover'
       import {Button} from '@/shadcn-components/ui/button'
       import {Input} from '@/shadcn-components/ui/input'

       export interface PendingStep {
         x: number
         y: number
         draftId: string
       }
       export interface TeachPopoverProps {
         pendingStep: PendingStep | null
         onCommit: (instruction: string) => void
         onCancel: () => void
       }

       function sanitize(s: string): string {
         // Minimal XSS guard for instruction preview (T-101-04). DOMPurify is dep-heavy;
         // for plain-text inputs we just strip < > and control chars.
         return s.replace(/[\x00-\x1f<>]/g, '').slice(0, 1024)
       }

       export function TeachPopover({pendingStep, onCommit, onCancel}: TeachPopoverProps) {
         const [draft, setDraft] = useState('')
         useEffect(() => { setDraft('') }, [pendingStep?.draftId])

         const virtualRef = useMemo(() => {
           if (!pendingStep) return null
           const {x, y} = pendingStep
           return {
             getBoundingClientRect: () => new DOMRect(x, y, 1, 1),
           }
         }, [pendingStep?.x, pendingStep?.y])

         if (!pendingStep || !virtualRef) return null
         const canSave = draft.trim().length > 0

         return (
           <Popover.Root open={true}>
             <Popover.Anchor virtualRef={virtualRef as any} />
             <Popover.Portal>
               <Popover.Content side='bottom' sideOffset={6} className='rounded-md bg-popover p-3 shadow-md w-80'>
                 <label className='text-xs font-medium block mb-1'>Bu adımı ne için yapıyorsun?</label>
                 <Input
                   autoFocus
                   value={draft}
                   onChange={(e) => setDraft(e.target.value)}
                   placeholder='Step description'
                 />
                 {draft.trim().length > 0 ? (
                   <div className='text-[10px] text-muted-foreground mt-1'>Preview: {sanitize(draft)}</div>
                 ) : null}
                 <div className='flex justify-end gap-2 mt-3'>
                   <Button variant='ghost' size='sm' onClick={onCancel}>Cancel</Button>
                   <Button size='sm' disabled={!canSave} onClick={() => onCommit(draft.trim())}>Save</Button>
                 </div>
               </Popover.Content>
             </Popover.Portal>
           </Popover.Root>
         )
       }
       ```
