    ## A) local-graph-mode.ts

    Pure TypeScript, zero React imports. Export:

    ```typescript
    export interface LocalGraphResult {
      nodes: GraphNode[]
      edges: GraphEdge[]
    }

    export function bfsSubgraph(
      graph: { nodes: GraphNode[]; edges: GraphEdge[] },
      focusId: string,
      depth: number,
    ): LocalGraphResult
    ```

    BFS algorithm:
    1. `depth = Math.min(4, Math.max(1, depth))` — clamp to [1,4]
    2. If focusId not found in graph.nodes → return `{nodes:[], edges:[]}`
    3. BFS: start queue = [focusId], visited = new Set([focusId])
    4. For each BFS level 1..depth: for each node in current frontier, gather neighbours via edges (both directions — source and target). Add unvisited neighbours to next frontier, mark visited.
    5. Return nodes where id ∈ visited; return edges where both source AND target ∈ visited.

    GraphNode and GraphEdge must be re-declared locally (or imported from a shared types file if one exists — check first via Grep; if none, declare inline with `export interface`).
