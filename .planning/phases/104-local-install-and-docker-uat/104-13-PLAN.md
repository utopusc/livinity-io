# Phase 104 Plan 13: pnpm blockExoticSubdeps hotfix for deploy-livinityd.sh

## Objective

Plan 104-12's mainserver re-test surfaced one more `pnpm install` failure on modern Ubuntu — pnpm 11.1.1 refuses to install `libsignal` (a `baileys` WhatsApp lib subdep that comes from `git-repository`):

```
[ERR_PNPM_EXOTIC_SUBDEP] Exotic dependency "libsignal" (resolved via git-repository)
is not allowed in subdependencies when blockExoticSubdeps is enabled
This error happened while installing the dependencies of @liv/core@1.0.0
 at baileys@6.7.21
[FAIL]  pnpm install failed
```

The Mini PC works because it has an older pnpm; modern Ubuntu 24.04 hosts running `install.sh` hit this. Fix: write `block-exotic-subdeps=false` to `/opt/livos/.npmrc` BEFORE `pnpm install` runs, so the legitimate `baileys → libsignal` chain installs cleanly.
