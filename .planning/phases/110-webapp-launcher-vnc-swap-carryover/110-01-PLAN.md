<task type="auto" name="Task 1: Mini PC smoke test — RFB 003.008 handshake against bruce's :0 (ephemeral, port 5933)">

**Action.** Single foreground SSH (test runs <5s; no detach needed; matches `reference_zerotier_unstable.md` exception "smoke test in this plan is short").

```bash
"/c/Windows/System32/OpenSSH/ssh.exe" \
  -i "C:/Users/hello/Desktop/Projects/contabo/pem/minipc" \
  -o StrictHostKeyChecking=no \
  -o UserKnownHostsFile=/dev/null \
  -o ConnectTimeout=10 \
  bruce@10.69.31.68 \
  'set -e
   echo "=== Pre-state ==="
   pgrep -af "x11vnc" || echo "no_x11vnc_running"
   echo "---"
   echo "=== Spawn ephemeral x11vnc on :0 (-localhost -rfbport 5933 -timeout 30 -shared -nopw) ==="
   nohup x11vnc -display :0 -localhost -rfbport 5933 -timeout 30 -shared -nopw -noxdamage > /tmp/p110-x11vnc.log 2>&1 &
   spawn_pid=$!
   sleep 1
   echo "spawn_pid=$spawn_pid"
   echo "---"
   echo "=== Capture RFB handshake banner via nc 127.0.0.1 5933 (12-byte read, 2s timeout) ==="
   banner=$(timeout 2 nc 127.0.0.1 5933 < /dev/null | head -c 12 | xxd | head -1)
   echo "banner_hex: $banner"
   echo "banner_ascii: $(timeout 2 nc 127.0.0.1 5933 < /dev/null | head -c 12)"
   echo "---"
   echo "=== Cleanup ==="
   pkill -f "x11vnc.*5933" 2>/dev/null || true
   sleep 1
   pgrep -af "x11vnc.*5933" && echo "WARN_STILL_RUNNING" || echo "cleanup_ok"
   echo "---"
   echo "=== Post-state ==="
   pgrep -af "x11vnc" || echo "no_x11vnc_running"
   echo "---"
   echo "=== x11vnc log tail ==="
   tail -20 /tmp/p110-x11vnc.log
  '
```

**Done.**
