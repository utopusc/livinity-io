<sanitize_snapshot>
<!-- T-197-05-01 mitigation. Locked design. -->

`sanitizeSnapshot(snapshot: unknown): unknown`:
- Recursively walks the value
- Replaces any string matching `/Bearer\s+[A-Za-z0-9._-]+/` with `'Bearer REDACTED'`
- Replaces any string matching `/postgresql:\/\/[^:]+:[^@]+@/` with `'postgresql://REDACTED:REDACTED@'`
- Replaces any object key matching `/(?:token|secret|password|api[_-]?key|authorization)/i` with `'<redacted>'` value (regardless of value type)
- Returns a NEW object tree (does not mutate input)

This runs BEFORE every snapshot write. Mastra's workflow persistence calls our wrapper which calls sanitizeSnapshot then forwards to PgStore.
</sanitize_snapshot>
