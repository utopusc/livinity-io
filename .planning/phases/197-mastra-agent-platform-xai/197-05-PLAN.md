<objective>
Bridge the Mastra agent (Plan 197-04) to the LivOS frontend via a 5-procedure tRPC namespace under `mastra.agent.*`. The marquee procedure is `agent.stream` — an SSE endpoint that emits Mastra's chunked stream output as typed events the UI can render. Wire HITL approval (`agent.approve`) — but the actual approve/reject pause-resume logic lives INSIDE the wrapped tool (W-02 lock, shipped by Plan 197-04); the tRPC layer is a transparent conduit that observes destructive tool-call chunks (detected by NAME via `destructiveToolNames` import — N-01 lock) and emits `tool-call-approval` SSE events. Wrap every error path through `redactError()` to defuse Mastra issue #15827 stack-trace leakage.

**W-02 lock — Reject is "tool-returned-denied", not "run-aborted":**
When the operator clicks Reject in the UI, `mastra.agent.approve` mutation calls `approvalManager.resolve(toolCallId, false)`. This unblocks the wrapped tool's execute() (Plan 197-04 `wrapToolWithApproval`), which returns the `REJECTED_TOOL_RESULT` sentinel `{rejected:true, reason:'operator rejected this tool call'}`. Mastra surfaces this as a tool-result chunk; the agent continuation produces a text reply explaining the rejection. The SSE layer does NOT abort the run on Reject. `mastra.agent.cancel` is a separate path for "stop the whole run."

       ```ts
       export interface PendingApproval {
         resolve(approved: boolean): void
         runId: string
         timeoutHandle: ReturnType<typeof setTimeout>
       }

       export class ApprovalManager {
         private pending = new Map<string /* toolCallId */, PendingApproval>()
         private timeoutMs: number

         constructor(opts?: {timeoutMs?: number}) {
           this.timeoutMs = opts?.timeoutMs ?? 5 * 60 * 1000  // 5 minutes
         }

         registerPending(toolCallId: string, runId: string): Promise<boolean> {
           return new Promise((resolve) => {
             const timeoutHandle = setTimeout(() => {
               // T-197-05-05 — auto-reject after timeout
               const entry = this.pending.get(toolCallId)
               if (entry) {
                 this.pending.delete(toolCallId)
                 entry.resolve(false)
               }
             }, this.timeoutMs)
             this.pending.set(toolCallId, {resolve, runId, timeoutHandle})
           })
         }

         resolve(toolCallId: string, approved: boolean): void {
           const entry = this.pending.get(toolCallId)
           if (!entry) return  // no-op (defensive — Test 3)
           clearTimeout(entry.timeoutHandle)
           this.pending.delete(toolCallId)
           entry.resolve(approved)
         }

         cancelAll(runId: string): void {
           for (const [toolCallId, entry] of this.pending.entries()) {
             if (entry.runId === runId) {
               clearTimeout(entry.timeoutHandle)
               this.pending.delete(toolCallId)
               entry.resolve(false)
             }
           }
         }
       }
       ```

       ```ts
       /**
        * Phase 197-05 T-197-05-02 — Mastra issue #15827 stack-trace leakage mitigation.
        * Returns a sanitized error shape: message preserved, stack replaced with '[redacted]'.

       export interface RedactedError {
         message: string
         code?: string
         stack: '[redacted]'
       }

       export function redactError(err: unknown): RedactedError {
         if (err instanceof Error) {
           const code = (err as {code?: string}).code
           return {
             message: err.message,
             ...(code !== undefined ? {code} : {}),
             stack: '[redacted]' as const,

                 }
       ```

       ```ts
                 }),
             }),
           }),

           }),
         }),
       ```
