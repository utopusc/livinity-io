The 4 Mastra tables we create (Mastra v1.35.x schema; verify column names against installed @mastra/memory at execution time and adapt if minor drift):

1. `mastra_threads` — one row per conversation thread
   - `id TEXT PRIMARY KEY`
   - `resource_id TEXT NOT NULL` (Mastra's "resource" concept — typically userId for LivOS)
   - `title TEXT`
   - `metadata JSONB DEFAULT '{}'::jsonb`
   - `created_at TIMESTAMPTZ NOT NULL DEFAULT now()`
   - `updated_at TIMESTAMPTZ NOT NULL DEFAULT now()`

2. `mastra_messages` — raw history layer + embeddings vector layer
   - `id TEXT PRIMARY KEY`
   - `thread_id TEXT NOT NULL REFERENCES mastra_threads(id) ON DELETE CASCADE`
   - `role TEXT NOT NULL CHECK (role IN ('user','assistant','system','tool'))`
   - `content JSONB NOT NULL`
   - `embedding vector(1536)` (nullable — embedding generated async)
   - `created_at TIMESTAMPTZ NOT NULL DEFAULT now()`
   - HNSW index on `embedding` with `vector_ip_ops` (dotproduct)

3. `mastra_working_memory` — compressed long-term observational memory per thread
   - `thread_id TEXT PRIMARY KEY REFERENCES mastra_threads(id) ON DELETE CASCADE`
   - `content TEXT NOT NULL DEFAULT ''`
   - `updated_at TIMESTAMPTZ NOT NULL DEFAULT now()`

4. `mastra_scorers` — eval scorer results (consumed by Plan 197-06 but table created here for migration cohesion)
   - `id TEXT PRIMARY KEY`
   - `agent_run_id TEXT NOT NULL`
   - `scorer_name TEXT NOT NULL`
   - `score NUMERIC NOT NULL`
   - `details JSONB DEFAULT '{}'::jsonb`
   - `created_at TIMESTAMPTZ NOT NULL DEFAULT now()`
   - Index on (`agent_run_id`, `scorer_name`)

If Mastra v1.35.x actual schema differs in column names (e.g. `threadId` camelCase vs `thread_id` snake_case), the executor MUST adapt to the actual Mastra-expected schema by reading `@mastra/pg`'s migration sources at the pinned version.        -- Phase 197-03 — Mastra memory schema migration.
       ```sql
       --
       -- Idempotent: every statement uses IF NOT EXISTS. Re-running this script
       -- on a DB where it has already applied produces zero diffs.
       --
       -- Additive only: zero DROP statements, zero data seeds. Existing v34/v38
       -- user/session/livos tables are untouched.
       --
       -- Apply via: psql -d livos -f scripts/install/migrations/197-mastra-pgvector.sql
       -- (assumes postgresql-16-pgvector apt package is installed; see plan's user_setup block)

       BEGIN;

       CREATE EXTENSION IF NOT EXISTS vector;

       CREATE TABLE IF NOT EXISTS mastra_threads (
           id          TEXT PRIMARY KEY,
           resource_id TEXT NOT NULL,
           title       TEXT,
           metadata    JSONB NOT NULL DEFAULT '{}'::jsonb,
           created_at  TIMESTAMPTZ NOT NULL DEFAULT now(),
           updated_at  TIMESTAMPTZ NOT NULL DEFAULT now()
       );

       CREATE INDEX IF NOT EXISTS mastra_threads_resource_id_idx
           ON mastra_threads(resource_id);

       CREATE TABLE IF NOT EXISTS mastra_messages (
           id         TEXT PRIMARY KEY,
           thread_id  TEXT NOT NULL REFERENCES mastra_threads(id) ON DELETE CASCADE,
           role       TEXT NOT NULL CHECK (role IN ('user','assistant','system','tool')),
           content    JSONB NOT NULL,
           embedding  vector(1536),
           created_at TIMESTAMPTZ NOT NULL DEFAULT now()
       );

       CREATE INDEX IF NOT EXISTS mastra_messages_thread_id_created_at_idx
           ON mastra_messages(thread_id, created_at);

       -- HNSW vector index for semantic recall (dotproduct metric per CONTEXT.md decision).
       CREATE INDEX IF NOT EXISTS mastra_messages_embedding_hnsw_idx
           ON mastra_messages
           USING hnsw (embedding vector_ip_ops);

       CREATE TABLE IF NOT EXISTS mastra_working_memory (
           thread_id  TEXT PRIMARY KEY REFERENCES mastra_threads(id) ON DELETE CASCADE,
           content    TEXT NOT NULL DEFAULT '',
           updated_at TIMESTAMPTZ NOT NULL DEFAULT now()
       );

       CREATE TABLE IF NOT EXISTS mastra_scorers (
           id           TEXT PRIMARY KEY,
           agent_run_id TEXT NOT NULL,
           scorer_name  TEXT NOT NULL,
           score        NUMERIC NOT NULL,
           details      JSONB NOT NULL DEFAULT '{}'::jsonb,
           created_at   TIMESTAMPTZ NOT NULL DEFAULT now()
       );

       CREATE INDEX IF NOT EXISTS mastra_scorers_agent_run_name_idx
           ON mastra_scorers(agent_run_id, scorer_name);

       COMMIT;
       ```

       ```ts
       // Phase 197-03 — LivOS Memory factory.
       //
       // 4-layer Mastra memory backed by the existing livos PostgreSQL database:
       //   1. lastMessages (raw history)  — N most recent messages prepended to context
       //   2. semanticRecall              — topK similar messages by HNSW vector lookup
       //   3. workingMemory               — observational summary updated incrementally per thread
       //   4. (compression)               — built into Mastra core; no config needed here
       //
       // SECURITY (T-197-03-01): connectionString accepted as constructor arg only —
       // we do NOT call process.env.DATABASE_URL inside this file. The caller
       // (Plan 197-04 tRPC bridge wire-up) is responsible for resolving the env var.
       // This keeps the factory test-hermetic and makes connection-leak audits trivial.
       import {Memory} from '@mastra/memory'
       import {PgStore, PgVector} from '@mastra/pg'

       export interface LivOSMemoryOptions {
         lastMessages?: number
         semanticRecall?: {topK?: number; messageRange?: number}
         workingMemory?: {enabled?: boolean}
       }

       export interface CreateLivOSMemoryArgs {
         connectionString: string
         options?: LivOSMemoryOptions
       }

       export function createLivOSMemory(args: CreateLivOSMemoryArgs): Memory {
         const lastMessages = args.options?.lastMessages ?? 20
         const topK = args.options?.semanticRecall?.topK ?? 5
         const messageRange = args.options?.semanticRecall?.messageRange ?? 2
         const workingMemoryEnabled = args.options?.workingMemory?.enabled ?? true

         const storage = new PgStore({connectionString: args.connectionString})
         const vector = new PgVector({
           connectionString: args.connectionString,
           indexConfig: {type: 'hnsw', metric: 'dotproduct'},
         })

         return new Memory({
           storage,
           vector,
           options: {
             lastMessages,
             // scope: 'thread' is EXPLICIT — Mastra changed default to 'resource' in 2026-03
             // (CONTEXT.md breaking-change flag). Re-asserting locks the LivOS contract.
             semanticRecall: {topK, messageRange, scope: 'thread'},
             workingMemory: {enabled: workingMemoryEnabled, scope: 'thread'},
           },
         })
       }
       ```
