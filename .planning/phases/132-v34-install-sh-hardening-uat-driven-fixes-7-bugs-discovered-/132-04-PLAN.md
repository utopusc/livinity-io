<objective>
Fix Bug #5: `livos/pnpm-workspace.yaml` has an `ignoredBuiltDependencies:`
list AND `livos/package.json` has a `pnpm.onlyBuiltDependencies` list with
the SAME 11 packages. In pnpm ≥10, `ignoredBuiltDependencies` is recognized
as the alias `neverBuiltDependencies`, and having both `neverBuiltDependencies`
+ `onlyBuiltDependencies` triggers
`ERR_PNPM_CONFIG_CONFLICT_BUILT_DEPENDENCIES`.

Fix: **remove the `ignoredBuiltDependencies` block from
`pnpm-workspace.yaml`** — the `pnpm.onlyBuiltDependencies` block in
`package.json` is the canonical pnpm 10+ surface and already lists the same
packages. On older pnpm (9.x) this is also valid; only the workspace.yaml
block was wrong-named for pnpm 10.

Lists are byte-identical (verified during UAT triage 2026-05-16) so this
is a pure dedup, no behavior change.
</objective>
