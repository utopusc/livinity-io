<objective>
Fix Bug #6: `scripts/install/deploy-livinityd.sh` ships the LivOS source
+ runs `pnpm install` for /opt/livos, but **never builds the /opt/liv/**
packages (`core`, `worker`, `mcp-server`, `memory`). On first boot,
livinityd imports `@liv/core` → pnpm symlink resolves to
`/opt/livos/node_modules/.pnpm/@liv+core@file*/node_modules/@liv/core/`
which has `src/` but no `dist/` → `ERR_MODULE_NOT_FOUND` for
`@liv/core/dist/lib.js` → service enters restart loop.

Fix: add a **liv/ build phase** after `pnpm install` and before
`systemctl start livos`:

1. `cd /opt/liv && npm install --production=false`
2. For each of `core`, `worker`, `mcp-server`, `memory`:
   `cd /opt/liv/packages/$pkg && npx tsc` (if dir exists)
3. Sync built `dist/` into the pnpm symlink target:
   `for d in /opt/livos/node_modules/.pnpm/@liv+core@file*/node_modules/@liv/core; do cp -r /opt/liv/packages/core/dist "$d/"; done`
4. Symlink UI dist into livinityd if not already done:
   `ln -sf /opt/livos/packages/ui/dist /opt/livos/packages/livinityd/ui`
5. `systemctl reset-failed livos && systemctl enable livos && systemctl start livos`

Depends on Plan 132-04 because the pnpm install step has to succeed first
(otherwise the symlink target dir doesn't even exist).
</objective>

Approximate structure (find the actual section by reading the file):

```bash
# ... existing: rsync /opt/livos/, pnpm install, build @livos/config, build UI ...

# ── Phase 132-05: liv/ packages build ──────────────────────
# Without this, livinityd boot fails ERR_MODULE_NOT_FOUND for
# @liv/core/dist/lib.js. See 132-CONTEXT.md bug #6.
info "Building liv/ packages (core, worker, mcp-server, memory)"
if [[ -d /opt/liv ]]; then
    cd /opt/liv && npm install --production=false 2>&1 | tail -5
    for pkg in core worker mcp-server memory; do
        if [[ -d "/opt/liv/packages/$pkg" ]]; then
            info "  Building liv/$pkg"
            cd "/opt/liv/packages/$pkg" && npx tsc 2>&1 | tail -3
        fi
    done
    # Sync core dist into pnpm symlink target (pnpm-store quirk —
    # file: protocol doesn't always propagate built artifacts)
    for d in /opt/livos/node_modules/.pnpm/@liv+core@file*/node_modules/@liv/core; do
        if [[ -d "$d" ]]; then
            cp -r /opt/liv/packages/core/dist "$d/"
            info "  Synced @liv/core/dist → $d"
        fi
    done
    ok "liv/ build complete"
else
    warn "/opt/liv not present — skipping liv/ build (UI-only install?)"
fi

# Symlink UI dist into livinityd workspace
ln -sf /opt/livos/packages/ui/dist /opt/livos/packages/livinityd/ui

# ── existing: systemctl daemon-reload + enable + start livos ──
```

Use the helper functions `info`, `ok`, `warn` already exported by `_logging.sh`.
