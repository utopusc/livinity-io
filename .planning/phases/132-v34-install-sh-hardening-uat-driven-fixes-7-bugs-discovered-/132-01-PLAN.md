<objective>
Fix Bug #1 (dashboard-install.html babel-standalone targets.esmodules error) +
Bug #2 (dashboard.html missing /dashboard/install nav link). Both fixes are
already applied **on-server** (Server5) as ad-hoc patches during UAT triage;
this plan back-ports them to the canonical source (if a source repo exists)
and documents the change.

Root cause #1: the script tag was `<script type="text/babel" data-type="module">`
— Babel-standalone interprets `data-type="module"` as `targets.esmodules = "module"`
(string), but Babel requires boolean. The transform fails silently for the user
(stuck on "Loading…"). Fix: remove `data-type="module"`.

Root cause #2: dashboard.html's nav has Dashboard / Changelog / Store but no
Install. Only first-run auto-redirect lands users on /dashboard/install.
Returning users can never find the wizard. Fix: add an
`<a href="/dashboard/install">Install</a>` link in the nav-links block.
</objective>
