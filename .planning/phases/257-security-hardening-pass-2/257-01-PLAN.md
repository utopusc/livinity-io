<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| GitHub remote → root update.sh | whatever HEAD the remote serves is rsync'd + built + restarted as root |
| community skill repo → liv-core process | a downloaded index.js is import()-ed in-process with full host privileges |
| network → curl\|bash installer | the piped script runs (as root in the sudo form) off the network |
| apt source → root update.sh | a blanket apt install on every run trusts the host's apt source set as root |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-257B-01 | Tampering / Elevation | update.sh deploys unverified HEAD as root | mitigate | verify fetched ref vs pinned/signed expected SHA; refuse on mismatch (Task 1) |
| T-257B-02 | Elevation of Privilege | skill index.js import() = in-process RCE | mitigate | verifySkillBundle checksum/signature gate before import; fail-closed (Task 3) |
| T-257B-03 | Tampering | curl\|bash installer runs unverified | mitigate | opt-in SHA pin before re-exec + documented verify-then-run + logged sha256 (Task 4) |
| T-257B-04 | Tampering | blanket unpinned apt every run | mitigate | gate apt install on a missing-binary check; skip when present (Task 2) |
| T-257B-05 | Repudiation | full signed-tag enforcement requires shipped maintainer key | accept (follow-up) | guard is opt-in-strict now; shipping EXPECTED_RELEASE / maintainer.gpg flips it to fail-closed (noted, out of this plan's repo-state) |
</threat_model>
