## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| stale JWT → tRPC after credential change | a still-valid signature is trusted with no revocation lookup |
| proxy/legacy token → /api/files | a user-agnostic proxy token resolves a file scope |
| session cookie → *.livinity.io | a widened cookie is attached to sibling/platform hosts |
| any minted token → any consumer | one shared secret + no aud/iss makes tokens interchangeable |
