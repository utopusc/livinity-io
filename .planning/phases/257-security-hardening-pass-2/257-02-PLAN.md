WS-C — Network & request-forgery surface. Close LIVOS-015 (livinityd admin daemon on :8080 binds the wildcard
address and UFW allows :8080 from Anywhere → the full management console is reachable by any LAN device),
LIVOS-024 (apps.addRepository — now admin-only via 256-03 — still issues git-smart-HTTP fetches to any
attacker-chosen host with no scheme/host allowlist → blind SSRF / metadata GET / internal port-scan), and
LIVOS-038 (the MCP streamableHttp SSRF guard checks only the LITERAL hostname against regexes → DNS-rebind, an
IPv4-mapped IPv6 literal, and decimal/hex IP encodings all bypass it).

flush doesn't re-expose it — defense in depth per the operator decision), a low-priv-but-authed user can no
longer drive livinityd to fetch internal targets, and a configured MCP URL can no longer rebind to a private IP.
Output: a loopback server bind, a UFW rule in the installer, the webapps SSRF validator wired into AppRepository,
and a resolve-and-check MCP SSRF guard.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| LAN device → livinityd :8080 | the admin console binds the wildcard and UFW allows the LAN |
| authed user → apps.addRepository | livinityd issues outbound git fetches to a user-chosen host (SSRF) |
| MCP config URL → liv-core transport | a configured streamableHttp URL can target internal services |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-257C-01 | Information Disclosure / Spoofing | :8080 LAN-exposed admin console | mitigate | loopback bind + UFW deny (Task 1); Caddy stays the front door |
| T-257C-02 | SSRF (Information Disclosure) | addRepository fetches internal targets | mitigate | webapps validateUrl scheme+isPrivateHost gate (Task 2) |
| T-257C-03 | SSRF (DNS-rebind/IPv6) | MCP streamableHttp literal-host check bypassed | mitigate | resolve + per-IP classification incl ::ffff:/decimal (Task 3) |
| T-257C-04 | Spoofing | overlay (ZeroTier/Tailscale) operator needs non-loopback bind | accept | LIVOS_BIND_HOST override preserves the legitimate overlay path (Task 1) |
| T-257C-05 | SSRF (redirect-follow) | MCP transport may follow a redirect to a private host | accept (residual) | resolved-IP pinning of the live socket is transport-internal; noted as a follow-up |
</threat_model>
