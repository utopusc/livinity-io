### T2 — POST /api/admin/sync-catalog
NEW `platform/web/src/app/api/admin/sync-catalog/route.ts`:
- POST endpoint, gated by `requireAdmin()`.
- Accepts query `?limit=N` (default 20, max 50).
- GitHub REST: `GET /repos/utopusc/livinity-apps/contents/apps?ref=main` → list directory.
- For each manifest entry (up to limit), fetch raw manifest JSON.
- Parse minimal schema: `{slug, name, category?, version?, tagline?, description?, docker_compose?, manifest?}`.
- Supabase UPSERT on `slug`:
  ```sql
  INSERT INTO apps (slug, name, tagline, description, category, version, docker_compose, manifest)
    VALUES (...)
    ON CONFLICT (slug) DO UPDATE SET
      name = EXCLUDED.name,
      tagline = EXCLUDED.tagline,
      description = EXCLUDED.description,
      category = COALESCE(EXCLUDED.category, apps.category),
      version = COALESCE(EXCLUDED.version, apps.version),
      docker_compose = COALESCE(EXCLUDED.docker_compose, apps.docker_compose),
      manifest = EXCLUDED.manifest,
      updated_at = NOW()
  ```
  (Operator-curated fields featured/verified/sort_order/icon_url/section are NOT touched.)
- Auth: use `GITHUB_TOKEN` env if present to raise rate limit.
- Return JSON: `{processed: N, created: M, updated: K, skipped: S, errors: [{slug, error}]}`.

**Commit:** `feat(214-01): T2 — POST /api/admin/sync-catalog (GitHub manifest upsert)`
