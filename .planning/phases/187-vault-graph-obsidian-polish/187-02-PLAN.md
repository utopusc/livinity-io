<objective>
Add `getOrphanRingColor(theme)` to graph-palette.ts and wire a `nodeCanvasObject` custom
painter in VaultGraph.tsx that draws a 1.5px red ring around nodes whose `wikiDegree === 0`.

Purpose: Isolated notes (no wikilinks) are invisible in the current graph. The
obsidian-second-brain visualize command uses a red border ring as its primary orphan signal.
This feature turns orphan detection from an explicit audit step into an always-on visual.

Output: New exported function in graph-palette.ts, new `nodeCanvasObject` prop in
VaultGraph.tsx ForceGraph2D, and 6 new passing vitest assertions.
</objective>

    ```typescript
    nodeCanvasObject={(node: any, ctx: CanvasRenderingContext2D) => {
      const scale = settings.display.nodeSizeScale
      const r = Math.sqrt(Math.max(1, node.degree ?? 0)) * scale * Math.sqrt(4 / Math.PI)
      // Base circle
      ctx.beginPath()
      ctx.arc(node.x ?? 0, node.y ?? 0, r, 0, 2 * Math.PI)
      ctx.fillStyle = node.color
      ctx.fill()
      // Orphan ring — only for wikiDegree === 0
      if ((node.wikiDegree ?? 0) === 0) {
        ctx.beginPath()
        ctx.arc(node.x ?? 0, node.y ?? 0, r + 1.5, 0, 2 * Math.PI)
        ctx.strokeStyle = getOrphanRingColor(theme)
        ctx.lineWidth = 1.5
        ctx.stroke()
      }
    }}
    ```
