GraphNode emitted by builder.ts. Wire ForceGraph2D's `nodeVal` prop so hub nodes render
larger circles proportional to their connection count.

#1 quality signal in a force-directed graph. Degree-proportional sizing is the canonical
Obsidian pattern — it costs zero user configuration.

    const degreeMap = new Map<string, { degree: number; wikiDegree: number }>()
    for (const n of nodes) degreeMap.set(n.id, { degree: 0, wikiDegree: 0 })
    for (const e of edges) {
      const src = degreeMap.get(e.source)
      const tgt = degreeMap.get(e.target)
      if (src) { src.degree++; if (e.type === 'wikilink') src.wikiDegree++ }
      if (tgt) { tgt.degree++; if (e.type === 'wikilink') tgt.wikiDegree++ }

    for (const n of nodes) {

      ;(n as any).degree = d.degree
      ;(n as any).wikiDegree = d.wikiDegree
    }
