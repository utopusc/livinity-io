# Plan 135-01 — DS Tokens + `OnboardingShell` Layout

**Wave:** 1 (foundational — all other plans build on this)
**Autonomous:** true
**Sacred SHA invariant:** preserved

## What

1. Port relevant Livinity DS CSS variables into LivOS UI as a scoped block.
2. Create a new layout component `OnboardingShell` (replacing `GradientLayout` for `/onboarding/*` routes only).
3. Swap the router entry to use `OnboardingShell`.

## Files touched

| File | Action |
|------|--------|
| `livos/packages/ui/src/styles/onboarding-tokens.css` (NEW) | Port DS `:root` vars under `[data-flow="onboarding"]` scope so the tokens only apply inside onboarding, not the rest of the app. |
| `livos/packages/ui/src/index.css` | Import the new tokens file. |
| `livos/packages/ui/src/layouts/onboarding-shell.tsx` (NEW) | New layout component — sets `data-flow="onboarding"` on root, renders an Apple-style centered card container with system fonts, max width `--max`, padding `--pad`. |
| `livos/packages/ui/src/router.tsx` | Replace `Component: GradientLayout` → `Component: OnboardingShell` for the `/onboarding` route. |

### 2. `layouts/onboarding-shell.tsx` (NEW)

```tsx
import {Outlet} from 'react-router-dom'

import '@/styles/onboarding-tokens.css'

/**
 * Phase 135 — Livinity DS-aligned shell for /onboarding/* routes.
 * Replaces the legacy GradientLayout (gradient glassmorphism) for these
 * routes only. Sets data-flow="onboarding" so the scoped tokens kick in.
 */
export function OnboardingShell() {
    return (
        <div
            data-flow="onboarding"
            style={{
                minHeight: '100vh',
                display: 'grid',
                placeItems: 'center',
                padding: 'var(--liv-pad)',
            }}
        >
            <div
                style={{
                    width: '100%',
                    maxWidth: 560,
                    background: 'var(--liv-bg)',
                }}
            >
                <Outlet />
            </div>
        </div>
    )
}

export default OnboardingShell
```
