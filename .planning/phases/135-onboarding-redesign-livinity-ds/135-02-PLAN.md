## How

### `index.tsx` — DS rewrite

**Before** (current):
```tsx
return (
    <Layout
        title={t('onboarding.start.title')}
        subTitle={t('onboarding.start.subtitle')}
        footer={<OnboardingFooter action={OnboardingAction.RESTORE} />}
        stepIndicator={<StepIndicator steps={3} currentStep={0} />}
    >
        <Link to='/onboarding/create-account' className={buttonClass} ref={continueLinkRef}>
            {t('onboarding.start.continue')}
        </Link>
    </Layout>
)
```

**After** (DS):
```tsx
return (
    <div className="liv-card" style={{display: 'flex', flexDirection: 'column', gap: 24}}>
        <header style={{display: 'flex', flexDirection: 'column', gap: 8}}>
            <DsStepIndicator steps={3} currentStep={0} />
            <h1 style={{fontSize: 32, fontWeight: 600}}>{t('onboarding.start.title')}</h1>
            <p style={{color: 'var(--liv-fg-mute)', fontSize: 17}}>
                {t('onboarding.start.subtitle')}
            </p>
        </header>
        <Link
            to='/onboarding/create-account'
            unstable_viewTransition
            ref={continueLinkRef}
            className="liv-btn"
            style={{display: 'inline-block', textAlign: 'center'}}
        >
            {t('onboarding.start.continue')}
        </Link>
        <OnboardingFooter action={OnboardingAction.RESTORE} />
    </div>
)
```

### `onboarding-footer.tsx` — DS rewrite

- Remove gradient-aware styling
- Use `var(--liv-fg-mute)` for text
- Use `var(--liv-line)` for separator
- Language picker dropdown styled via DS tokens

### Step indicator

If `components/ui/step-indicator.tsx` uses gradient/accent colors, port it to use DS `--liv-accent` + `--liv-fg-faint` for inactive dots. If it's already neutral, leave it.

Check actual styling via Read first.
