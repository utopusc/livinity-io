## What

Redesign the 5 components in `livos/packages/ui/src/features/local-setup/`:

| File | LOC | Role |
|------|-----|------|
| `LocalSetupWizard.tsx` | 380 | Wizard shell — orchestrates 4 steps |
| `ModePickStep.tsx` | 94 | Step 1 — pick hybrid / local-lan / cloud |
| `HybridDnsSetup.tsx` | 85 | Step 2a — DNS + CF token capture |
| `PlatformInstructions.tsx` | 124 | Step 2b — per-platform (Mac/iOS/Win) DNS instructions |
| `QrCodeStep.tsx` | 56 | Step 3 — QR for mobile access |

These are the inner-step components used by the setup-wizard for the "local install" branch. They're embedded inside `setup-wizard.tsx` flow but live as separate files.

## Files touched

All 5 files above. Plus possibly `types.ts` for shared shape changes (none expected).

## How

Apply DS aesthetic per the same recipe as 135-02 / 135-03 / 135-04:

### `LocalSetupWizard.tsx` (the shell)

- Replace card/panel wrappers with `.liv-card`
- Use DS step indicator instead of legacy
- Back/Next buttons → DS button primary/secondary
- Preserve state machine logic

### `ModePickStep.tsx` (94 LOC)

Mode picker is again card-list. Same recipe as 135-03's mode picker:
- Each mode = horizontal radio card
- Selected: `border-color: var(--liv-fg)`, `background: var(--liv-accent-soft)`
- Unselected: `border-color: var(--liv-line)`, hover `border-color: var(--liv-line-strong)`
- Icon (if present) keeps its color identity (e.g., a Cloudflare logo stays orange)

### `HybridDnsSetup.tsx` (85 LOC)

Form: CF API token input + domain input. Re-skin with DS form inputs from 135-04's `DsLabeledInput`.

### `PlatformInstructions.tsx` (124 LOC)

Per-platform (Mac/iOS/Windows) instructions — likely a tabbed view. Tabs use DS aesthetic:
- Active tab: `border-bottom: 2px solid var(--liv-fg)`, `color: var(--liv-fg)`
- Inactive tab: `color: var(--liv-fg-mute)`, no border
- Tab body: plain text + maybe code blocks → use `var(--liv-mono)` font for code blocks

### `QrCodeStep.tsx` (56 LOC)

QR code rendered on white card. Around the QR: title + sub-text in DS typography. QR itself stays as-is (the QR image generator outputs neutral B/W which already fits DS).
