  <name>Task 1: Internal plugin RPC surface in livinityd</name>
  <action>
    Create `livos/packages/livinityd/source/modules/openclawos/plugin-rpc.ts`. Express RequestHandler:
    1. Validate `req.headers['x-internal-plugin-token']` against `process.env.LIV_PLUGIN_TOKEN`. If mismatch → 403.
    2. Parse `{ method, args }` from body.
    3. Dispatch table:
       - `luse.invoke(toolName, args)` → forwards to existing `mcpBridge.callTool('luse', toolName, args)`
       - `builtin.invoke(toolName, args)` → forwards to existing `BUILT_IN_TOOL_CATALOG` execute function (Phase 200-C + 202-08)
       - `approval.request({toolName, args, agentId, userId})` → forwards to `approvalManager.request(...)` and AWAITS the user decision (long-poll, max 5 min)
    4. Return result JSON or `{ error: 'METHOD_NOT_FOUND' | 'APPROVAL_REJECTED' | 'TOOL_ERROR' }`.

    Mount in `livinityd/source/index.ts` next to `/openclawos/handshake`.
  </action>
  <verify>
    <automated>cd livos && pnpm --filter livinityd test -- plugin-rpc</automated>
  </verify>
  <done>5+ tests PASS (token-missing → 403, valid luse call → result, approval-rejected → error code, unknown method → 404)</done>
</task>
