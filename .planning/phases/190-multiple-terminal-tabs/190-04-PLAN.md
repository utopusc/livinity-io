<objective>
Add additive localStorage persistence to the tab state introduced in Plan 190-03. On mount,
restore any previously-persisted tabs. On every tabs change, write to localStorage after a 300ms
debounce. Storage key is user-scoped: `liv:ai-chat:tabs:{userId}`.

Purpose: Page refreshes or window re-opens restore the operator's tab layout. Tmux sessions are
already persistent (outlive livinityd by design per D-V35-A), so restored tabs re-attach to the
live PTY session.

Output: 6 new vitest assertions + additive edits to index.tsx only.
</objective>
