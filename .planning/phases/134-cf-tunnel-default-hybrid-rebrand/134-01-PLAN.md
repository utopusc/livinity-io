# Plan 134-01 — Refactor install.sh: hybrid mode uses CF Tunnel transport

**Wave:** 1 (parallel with 134-02)
**Autonomous:** true
**Sacred SHA invariant:** `f3538e1d811992b782a9bb057d1b7f0a0189f95f` on `liv/packages/core/src/sdk-agent-runner.ts`

## What

Make `--mode hybrid` (the default) use cloudflared / CF Tunnel as its transport. Retire the Caddy-LE-DNS-01 + A-record-to-LAN-IP direct-LAN path. Keep `--mode tunnel` as a backward-compat alias. Drop the `--cf-zone-id` requirement.

## Files changed

| File | Change |
|------|--------|
| `scripts/install/mode-hybrid.sh` | **Gutted + rewritten.** New body delegates to mode-tunnel.sh's `install_mode_tunnel`. Removes `_verify_caddy_cloudflare_plugin`, `_write_cf_token_secret`, `_provision_hybrid_subdomain`, `_provision_user_owned_domain`. ~270 lines → ~30 lines. |
| `scripts/install/parse-cli.sh` | `--cf-tunnel-token` now valid in BOTH `hybrid` and `tunnel` modes. `--cf-zone-id` no longer required (was already optional for tunnel; now removed from hybrid gating). `--cf-token` becomes optional in hybrid (only needed if operator opts into DNS-record auto-create outside the wizard). Help text rewritten. |
| `scripts/install.sh` | `case` dispatch: `hybrid` and `tunnel` both source `mode-tunnel.sh` → call `install_mode_tunnel`. Comment block updated. |
| `scripts/install/__tests__/test-parse-cli-args.sh` (existing) | Update fixture expectations: hybrid mode no longer requires `--cf-zone-id`. New expectations: hybrid+`--cf-tunnel-token` is a valid combo. |

## How

### 1. Rewrite `mode-hybrid.sh` (gut → delegate)

```bash
# scripts/install/mode-hybrid.sh
# Phase 134 — hybrid mode now uses CF Tunnel as transport.
# D-134-MODE: --mode hybrid is the default user-facing mode and transparently
# implements Cloudflare Tunnel (cloudflared outbound). Direct-LAN retired.
# D-134-MODE-ALIAS: --mode tunnel still works (backward compat); both flags
# land in install_mode_tunnel from mode-tunnel.sh.
#
# Pre-Phase-134 (104-04 + 104-08): xcaddy + caddy-dns/cloudflare + LE DNS-01
# A-record-to-LAN-IP path. RETIRED — required public IP / port-forward and
# failed silently behind CGNAT / no-public-IP / Client Isolation (the exact
# Mini PC blocker that drove this phase).

# Source mode-tunnel.sh so install_mode_tunnel is in scope.
source "$SCRIPT_DIR/mode-tunnel.sh"

# Public entry point (still called by scripts/install.sh case dispatch).
# Thin wrapper preserves the install_mode_hybrid name so old call sites /
# external scripts grepping for it don't break.
install_mode_hybrid() {
    info "Hybrid mode (Phase 134): using Cloudflare Tunnel as transport"
    install_mode_tunnel
}
```

### 2. Update `parse-cli.sh`

- Add `hybrid` to the modes where `--cf-tunnel-token` is valid (alongside `tunnel`).
- Remove `--cf-zone-id` from the hybrid gating block (was: required when `--domain` set).
- Update `--cf-tunnel-token` rejection block: only reject in `cloud` and `local-lan`.
- Update help text examples to lead with the tunnel-via-hybrid one-liner.

Diff sketch:
```diff
# parse-cli.sh : tunnel-mode gating block
-if [[ "$MODE" == "tunnel" ]]; then
+if [[ "$MODE" == "tunnel" || "$MODE" == "hybrid" ]]; then
     local missing=""
     [[ -z "$LIVOS_DOMAIN" ]] && missing+=" --domain"
     [[ -z "$LIVOS_CF_TUNNEL_TOKEN" ]] && missing+=" --cf-tunnel-token"
     if [[ -n "$missing" ]]; then
-        echo "ERROR: --mode tunnel requires:$missing" >&2
+        echo "ERROR: --mode $MODE requires:$missing" >&2
         echo "See: bash install.sh --help" >&2
         exit 64
     fi
 elif [[ -n "$LIVOS_CF_TUNNEL_TOKEN" ]]; then
-    echo "ERROR: --cf-tunnel-token is only valid with --mode tunnel (got --mode $MODE)" >&2
+    echo "ERROR: --cf-tunnel-token is only valid with --mode hybrid or --mode tunnel (got --mode $MODE)" >&2
     exit 64
 fi
```

- Drop the `--cf-zone-id`-required-in-hybrid validation entirely (it's no longer used by mode-hybrid.sh after the rewrite; the wizard mints DNS records server-side via CF API now).
- Keep `LIVOS_CF_TOKEN` / `LIVOS_CF_ZONE_ID` env vars optional + harmless (forward-compat).
