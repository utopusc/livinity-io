# Plan 134-05 — UAT: Mini PC migration + anywhere-access proof

**Wave:** 3 (after 134-01, 134-03, 134-04 land)
**Autonomous:** true (autonomous SSH walk to Mini PC, then operator phone evidence)
**Sacred SHA invariant:** preserved (verified on Mini PC post-deploy)

## What

Walk the end-to-end migration on the user's Mini PC: SSH in, fetch the CF Tunnel token (via wizard if 134-02 also shipped, OR manually if Server5 deferred), run `migrate-to-cf-tunnel.sh`, verify `bruce.livinity.live` reachable from outside-LAN (mobile data simulation via Server5 or evidence-only operator screenshot).

## Prerequisites

- 134-01 shipped: `--mode hybrid` and `migrate-to-cf-tunnel.sh` available on Mini PC after `update.sh` pulls the latest commit.
- 134-03 shipped: migration script in repo.
- One of:
  - 134-02 shipped: wizard auto-provisions the tunnel token (operator clicks Generate at livinity.io/dashboard/install).
  - 134-02 deferred: operator manually creates a tunnel in CF Zero Trust dashboard and pastes the token.

## Steps

### 1. Pre-UAT sacred SHA check (Mini PC)

```bash
SSH="ssh -i C:/Users/hello/Desktop/Projects/contabo/pem/minipc -o StrictHostKeyChecking=no -o UserKnownHostsFile=/dev/null bruce@100.112.68.1"
$SSH 'git -C /opt/liv hash-object packages/core/src/sdk-agent-runner.ts'
# expected: f3538e1d811992b782a9bb057d1b7f0a0189f95f
```

### 2. Pull latest LivOS code to Mini PC

```bash
$SSH 'sudo bash /opt/livos/update.sh 2>&1 | tail -50'
# Expected: services restart cleanly, sacred SHA still f3538e1d…
```

### 3. Capture pre-migration state snapshot

```bash
$SSH 'sudo redis-cli --no-auth-warning -a "$(grep -oP "(?<=:)[^@]+(?=@)" /opt/livos/.env | head -1)" \
    HGETALL livos:domain:config 2>&1 ; \
    sudo cat /etc/caddy/Caddyfile ; \
    sudo systemctl is-active caddy cloudflared livos liv-core'
```

Save output to `.planning/phases/134-cf-tunnel-default-hybrid-rebrand/UAT-EVIDENCE/pre-migration-state.txt`.

### 4. Obtain CF Tunnel token

**Path A (134-02 shipped):**
```
Operator opens https://livinity.io/dashboard/install → enters domain `bruce.livinity.live` →
clicks Generate → copies the one-liner. Token embedded.
```

**Path B (134-02 deferred):**
```
Operator opens https://dash.cloudflare.com → Zero Trust → Networks → Tunnels → Create
→ name "livos-bruce" → installs connector → copies token.
```

Token stored in env var `CF_TUNNEL_TOKEN_BRUCE` for the UAT walk.

### 5. Run migration script

```bash
$SSH "sudo bash /opt/liv/scripts/install/migrate-to-cf-tunnel.sh \
    --domain bruce.livinity.live \
    --cf-tunnel-token $CF_TUNNEL_TOKEN_BRUCE 2>&1 | tee /tmp/migrate-134-output.log"
```

Expected: all 15 steps print success, exit 0.

Save output to `UAT-EVIDENCE/migrate-output.log`.

### 6. Post-migration verification on Mini PC

```bash
$SSH 'sudo systemctl is-active caddy cloudflared livos liv-core'
# expected: all "active"

$SSH 'sudo redis-cli --no-auth-warning -a "$(grep -oP "(?<=:)[^@]+(?=@)" /opt/livos/.env | head -1)" \
    GET livos:domain:local_mode'
# expected: "tunnel"

$SSH 'curl -fsS http://127.0.0.1:80/ -o /dev/null -w "%{http_code}\n"'
# expected: 200 (Caddy → livinityd reverse proxy)

$SSH 'sudo journalctl -u cloudflared --since "5 minutes ago" --no-pager | tail -20'
# expected: "Registered tunnel connection" line(s)
```

Save outputs to `UAT-EVIDENCE/post-migration-services.txt`, `post-migration-redis.txt`, `post-migration-curl-localhost.txt`, `post-migration-cloudflared-journal.txt`.
