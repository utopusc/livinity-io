<objective>
WS1 — kill the restart storm. Phase 267-03's `triggerAgentRefresh()` fires `sudo systemctl restart liv-assistant` on EVERY successful auth / setApiKey / uninstall; each restart takes AionUi (:3020) down ~40s → the whole `/liv/api/*` surface returns 502 (the operator hit repeated "Bad gateway 502 / AionUi çöktü" doing a few uninstalls + a claude auth).

Replace the 3 auto-restart call sites with a Redis pending-changes flag, add a user-triggered `cliInstaller.applyAgentChanges` route (calls `scheduleAgentRefresh` exactly ONCE + clears the flag) and a `cliInstaller.hasPendingAgentChanges` query, surface an "Apply changes (refresh Liv AI)" button in BOTH the dialog and the panel, and extend the Caddy + httpOnlyPaths plumbing for the 2 new routes. `agent-refresh.ts` stays byte-for-byte unchanged.

Purpose: the operator batches install/auth/uninstall actions and triggers exactly ONE restart when ready — no 502 storm.
Output: a manual-apply flow end to end (router + transport + Caddy + dialog + panel) with the same debounced restart helper reused once.
</objective>
