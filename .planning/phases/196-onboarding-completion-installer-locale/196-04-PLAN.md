<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| operator-browser → tRPC setup.setRegion | New ingress added in this plan; gated by adminProcedure (admin-only) + zod allow-list. |
| livinityd → Redis liv:user:region | Internal trust boundary; livinityd owns the Redis client. |
| Cloudflare CF-IPCountry header → countryToRegion | UNTRUSTED INPUT — Cloudflare adds the header but a self-hosted Caddy can be configured to pass through arbitrary client-supplied headers. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-196-04-01 | Tampering | Client sends `region: 'mars'` via direct tRPC call | mitigate | zod `z.enum([...REGIONS])` rejects with BAD_REQUEST before the procedure body runs. Test 3 in setup-router.test.ts regression-locks this. |
| T-196-04-02 | Tampering | Client sends `country: '../etc/passwd'` to attempt path traversal via Redis key | mitigate | zod `z.string().regex(/^[A-Z]{2}$/)` enforces 2-letter uppercase. Defense-in-depth: even if the regex were bypassed, Redis SET with the value as the VALUE (not the KEY) makes path traversal impossible. The KEY is hard-coded `liv:user:country`. |
| T-196-04-03 | Spoofing | Attacker spoofs CF-IPCountry header at the Caddy seam to mislead suggestion | accept | Suggestion is advisory only; the operator can override. Persisted region is whatever the operator confirms. Test 6 (selecting a different card) regression-locks the override flow. |
| T-196-04-04 | Elevation of Privilege | Non-admin user calls setup.setRegion | mitigate | adminProcedure gate (mirrors Phase 195-03 T-195-03-01). Test 6 in setup-router.test.ts regression-locks this. |
| T-196-04-05 | Information Disclosure | Region/country values leak via logs | accept | Region is non-sensitive (continent-level). Country is ISO-2 — minimal PII. Standard logging applies; no special redaction needed. |
| T-196-04-06 | Denial of Service | setRegion called repeatedly to flood Redis | accept | adminProcedure gate limits this to authenticated operators. A flood from an admin is a higher-severity compromise already. |
</threat_model>
