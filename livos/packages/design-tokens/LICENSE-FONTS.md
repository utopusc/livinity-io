licensed under the **SIL Open Font License, Version 1.1** (OFL 1.1). The full
license text is canonical and available at the SIL website and in each font's
upstream source repository.

## License — SIL Open Font License 1.1

The OFL 1.1 permits redistribution and modification provided that:

1. The fonts may not be sold by themselves.
2. The fonts must be bundled with software (this package qualifies — `@livinity/design-tokens`).
3. Derivative fonts must not use any Reserved Font Name from the upstream license.
4. The full license text must accompany every distribution.

Full canonical text: https://scripts.sil.org/cms/scripts/page.php?site_id=nrsi&id=OFL_web

## Attribution

When LivOS or any downstream surface displays these fonts to end users, no
visible attribution is required by the OFL. The credit-trail is preserved here
in the source-of-truth package metadata.

## Verification

Each `.woff2` file's download URL + SHA-256 + retrieval date is recorded in
`fonts/SOURCES.md`. The files are byte-identical to upstream canonical builds.
