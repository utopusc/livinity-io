Livinity Desktop v0.2.0 Beta

Livinity Desktop for Windows.

Zero terminal. Sign in, and your personal AI home server installs itself — Livinity Desktop sets everything up in the background and keeps it running from the system tray.

Download for Windows View release on GitHub

.exe installer·100 MB·Windows 10 / 11, 64-bit

On macOS or Linux? Install LivOS directly with the one-line installer.

A note about Windows SmartScreen

Livinity Desktop is a beta and isn't code-signed yet, so Windows may show a SmartScreen prompt the first time you run the installer. Click More info, then Run anyway. After installation, updates download and apply automatically.

System requirements

Operating systemWindows 10 (version 2004 or later) or Windows 11
Architecture64-bit (x64)
VirtualizationEnabled in BIOS/UEFI — on by default on most PCs; the app tells you if it isn't
Disk spaceAbout 15 GB free
WSL 2Required — Livinity Desktop enables it for you, no manual steps
01 · How it works

From download to online, in three steps.

Step 1

Install

Run the installer and open Livinity Desktop. No terminal, no configuration files — just a normal Windows app.

Step 2

Sign in

Use your livinity.io account. The app checks your plan and prepares the right setup for you.

Step 3

Your server comes online

Livinity Desktop enables WSL 2, installs LivOS, and connects your subdomain. Your server stays running — supervised from the tray.
